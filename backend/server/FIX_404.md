# 修复 404 错误 - 快速指南

## 问题

访问 `http://localhost:8080/api/quant/news/checkMeilisearchConsistency` 返回 404

## 原因

后端服务需要重启以加载新添加的路由配置。

## 解决方案（3 步）

### 步骤 1: 停止当前服务

找到并停止正在运行的 Go 服务：

```bash
# 方法 1: 如果在终端运行
按 Ctrl+C

# 方法 2: 查找并杀死进程
ps aux | grep "go run main.go"
kill -9 <进程ID>

# 或者
ps aux | grep "./app"
kill -9 <进程ID>

# 方法 3: 杀死所有占用 8080 端口的进程
lsof -ti:8080 | xargs kill -9
```

### 步骤 2: 重新启动服务

```bash
cd server
go run main.go
```

### 步骤 3: 验证服务

等待服务启动完成，查看日志应该包含：

```
Meilisearch client initialized successfully
News index created and configured successfully
```

然后测试 API：

```bash
curl http://localhost:8080/api/quant/news/checkMeilisearchConsistency
```

## 快速诊断

运行诊断脚本：

```bash
cd server
chmod +x check_routes.sh
./check_routes.sh
```

## 验证成功

如果一切正常，你应该看到：

- ✓ 后端服务正在运行
- ✓ 端口 8080 已被占用
- ✓ 接口可访问 (HTTP 200 或 401)
- ✓ 函数和路由已定义

## 前端测试

1. 打开浏览器访问新闻管理页面
2. 点击"数据一致性检查"按钮
3. 应该能看到检查结果

## 常见问题

### Q: 端口被占用怎么办？

```bash
# 查看占用端口的进程
lsof -i :8080

# 杀死进程
kill -9 <PID>
```

### Q: 服务启动失败？

检查：

1. 是否在 server 目录下
2. go.mod 文件是否存在
3. 配置文件 config.yaml 是否正确

### Q: 仍然返回 404？

1. 确认服务已重启（不是热重载）
2. 检查日志是否有错误
3. 运行诊断脚本查看详细信息

## 新增的 API 路由

已添加到 `server/router/quant/news.go`：

```go
// GET 请求 - 不需要操作记录
newsRouterWithoutRecord.GET("checkMeilisearchConsistency", newsApi.CheckMeilisearchConsistency)

// POST 请求 - 需要操作记录
newsRouter.POST("fullSyncToMeilisearch", newsApi.FullSyncToMeilisearch)
```

完整 URL：

- `GET  http://localhost:8080/api/quant/news/checkMeilisearchConsistency`
- `POST http://localhost:8080/api/quant/news/fullSyncToMeilisearch`

## 总结

**最简单的解决方法：**

1. 停止服务（Ctrl+C 或 kill）
2. 重新运行 `go run main.go`
3. 等待启动完成
4. 测试接口

**记住：** 每次修改路由配置后都需要重启服务！
