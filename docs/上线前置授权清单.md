> **这些是"不办就侵权 / 不办就违规"的硬义务，且都不是写代码能解决的。**
> 它们的共同特点是：**开发期完全不影响，上线当天才炸**。因此单列一份清单，
> 由 CI 每次构建打印，保持可见。
>
> 状态标记：`⛔ 未开始` / `🔄 进行中` / `✅ 已完成`
> **每项完成后必须填写凭证位置**（合同号 / 归档路径），空着不算完成。

## 1. gin-vue-admin BSL 商业授权

- **状态**：⛔ 未开始
- **依据**：[ADR-0004](adr/0004-后端采用gin-vue-admin.md)
- **为什么必须**：v3.0.0 采用 BSL 1.1，
  *"You may not make Production Use ... except as expressly permitted by a separate
  commercial license obtained from the Licensor."*
- **对方**：北京翻转极光科技有限责任公司 / business@gin-vue-admin.com
- **开发期是否受限**：可用于内部开发评估，但**不得**处理真实用户数据、
  **不得**公网可访问、**不得**部署给第三方
- **凭证归档位置**：（待填）

## 2. 行情数据商用授权（延时 15 分钟）

- **状态**：⛔ 未开始
- **依据**：`.claude/agents/compliance-redline.md` §行情数据授权
- **为什么必须**：展示个股涨跌幅 = 使用沪深交易所行情数据，商用须授权。
  这与证券投顾牌照是**两件不同的事**，不能相互替代。
- **候选来源**：上证信息 / 深证信息 / 恒生 / 万得 / 同花顺开放平台
- **一期口径**：延时 15 分钟（已定）
- **开发期替代**：使用**明确标注**的模拟数据（"示例数据，非真实行情"）
- **禁止**：抓取新浪/腾讯/东财免费网页接口支撑正式产品
- **凭证归档位置**：（待填）
