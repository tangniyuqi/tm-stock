所有公司与内容均为示意；没有使用真实行情、真实用户或正式收费数字。价格尚未确定，因此解锁按钮展示禁用态，正式界面需在取得有效报价与余额后允许确认。

本组说明核心布局，尚未覆盖会员未开通、余额不足、支付失败、投稿错误及审核结果等后续状态。已解锁页示意选择了社区补充，不表示购买 AI 内容自动获得其他作者文章权限；授权按具体内容区分。

投稿页“添加来源材料”后续需展开来源类型、原文链接、原文摘录及披露时点字段，采集时点由服务端记录。基础证据不因收费被遮挡。分享只包含允许公开的摘要。

生成：Windows 安装 Pillow 后执行 `python docs/prototypes/member-points/render.py`。默认使用系统微软雅黑字体，输出双倍分辨率 PNG。图片已经目视检查，未作为客户端运行或接口联调验证。
