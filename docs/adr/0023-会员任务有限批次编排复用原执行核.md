# ADR-0023：会员任务有限批次编排复用原执行核

- 状态：服务核与双版本专项已实现/验证；全套回归继续验收，不启用真实Agent、模型、收费、后台服务或部署。
- 背景：会员创建与单任务L1链路已接线，但调用方仍须指定每个任务编号；现有仓储候选查询没有对应的会员队列执行边界，不能把“写入排队”当成自动交付。

## 决定

1. 增加服务层`AIL1ReportQueue`，只接收既有`AIL1ReportWorker`，复用单任务`Run`及其原准入、租约、围栏、预留、隔离、转换、判定和原子终检；不复制执行逻辑，不新增CLI/公开路由、循环服务或隐含开关。
2. 每批以数据库UTC和任务主键上界固定窗口，按主键读取有限行的最小元数据，再判断有准入标记的到时L1题材任务。不得先按稀疏资格过滤再用LIMIT掩盖无界历史扫描。旧内部任务、L2、专题、将来可执行任务只计跳过，不执行。候选是提示，不授予租约或模型/来源许可；执行前仍按账户→任务当前读复核完整准入记录与数据库当前时点，原`Run`重新核对当前授权并原子抢占。
3. 单次最多处理100行，额外读取一行判断是否还有下一页，总期限最多五分钟并服从父上下文，扫描查询另有三秒期限；同一队列实例不重入，不并行启动模型或持数据库锁等待网络。有限键集扫描不是生产容量/公平性承诺，现有主键范围查询在上线前仍需真实数据量验证。
4. 其他worker已取得租约或候选已终结时明确记为延后/观察，不算新交付。存储、缺失依赖、准入、未知提交或其他非竞争错误立即返回原错误与已确认的有限进度；不把笼统的NotFound当竞争，不换键、不补冻结、不退款，不自动重试。单任务返回响应不明时仅记录该封闭状态，不伪装为成功。
5. 游标只属于本轮固定窗口。读完后新一轮从零扫描，不能把它当永久消费偏移，否则会漏掉本轮尚未到时的低编号任务。返回白名单任务状态/封闭结果与扫描进度，不返回正文、许可、预算或账务金额；“窗口扫描完成”不等于所有任务成功、报告可见或结算已确认。
6. 独立过期清扫与会员取消不依赖本入口。来源撤回或执行准入失效不授权补记录/补调用；损坏记录阻止队列执行，但原取消/过期事务仍可回收冻结。真实生产控制器、价格簿、质量及远端硬预算证明缺失时继续拒绝启用。

## 验收

单元与MySQL8.0.46/9.7.0真库使用显著示例来源和回环模型：HTTP新建后仅通过队列入口驱动至报告与结算；覆盖有限游标、空队列、非会员/不支持任务排除、同候选竞争、来源撤回、关闭、取消/过期、提交未知与原结果恢复。各任务保持原单次提交/冻结与单笔终结；任何前缀、准入或读取故障不得被“已访问”掩盖为已交付。双版本专项RC/RR已通过同实例及独立worker各12路竞争，扫描取消误报完成的单元反例已复现并修正；完整冻结回归另见任务记录，不提前勾选完整主链路或L1/L2关口。
