# ADR-0020：会员报告读取复核终检与当前授权

- 状态：开发中；真实调用、收费、生产部署与公众读取保持关闭。
- 背景：任务成功和报告行存在不等于可向会员展示；不能绕过原结算链核验或继续展示已撤回来源。

## 决定

1. 新增独立报告GET，身份复用当前会员JWT与实时会员状态，不接受用户编号、提示词或报告正文。本人之外与不存在统一404；本人未交付或来源/可见审批不可用时不返回任何正文。
2. 复用原终检的完整前缀、不可变报告、任务终态/事件、原冻结锁价/结算流水核验。仅成功报告可读；不调用Review或模型，不创建事件、不冻结/补扣/释放积分。
3. 当前策略重新Decode/Bind，当前来源授权/副本/精确URL/题材以数据库共享当前读复核。读取前后持久链复核，中间及返回前分别检查当前发布准入；任何存储/提交未知、撤回、策略或质量证明缺失均返回空结果。授权复核是读取时点的保证，不声称能撤回已发送的字节。
4. 发布控制器只接收白名单元数据，不接Agent原文、提示或许可内容；必须检查真实模型/质量/公示/当前可见授权。没有生产默认通过实现。报告开关独立默认关闭，开启但缺真实控制器/策略则整个API启动失败，不因开发付费放行而注册路由。
5. 对外DTO只含题材、生成时点、AI标识/模型公示、固定章节、逐字事实及来源链接/类别/采集时点；不返回内部任务号、幂等键、围栏、预算、快照编号/偏移、许可归档、内部判定或原始JSON。响应no-store，页面按纯文本渲染。
6. 页面仅解释已通过闭集验证的当前任务状态：六种失败原因使用固定中文，不显示服务端/供应商任意文字，不把执行预算限制称为会员积分不足。取消不承诺远端停止或退款；成功状态不授予报告读取权。不可逆取消标志在终态可留存审计，只有排队/运行态才显示等待取消确认，不能把旧标志当成终态仍未确认。重新查询、切任务/账号和离页清除旧说明，状态说明不发起任何写入或模型调用。

## 后果与验收

报告读取为复用已有一致性核而短暂锁账户/任务，随后共享锁来源；虽然无业务写入，不等于仅SELECT权限或无锁查询。必须有限上下文，保留既有锁序；大历史/高频读取吞吐未验，不承诺生产容量。进度详情可通过独立可用性核验返回true，列表保持不联表且不推导可用性。

用模拟发布控制器、明确示例来源和真实SQL验证：成功读取且无账务/事件/模型变化；跨用户/管理员/停用会员拒绝；来源与发布批准撤回、链损坏、失败/未完成报告、读取回执不明不泄漏；重复/并发读取不扣费；MySQL8/9与本地页面分别取证。该接线不代替真实发布证明、完整L1/L2或上线确认。
