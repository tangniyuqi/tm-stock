# ADR-0016：报告终检与锁价结算原子提交

- 状态：内部开发与隔离测试；不开放真实调用或公众入口
- 日期：2026-10-16
- 依据：用户要求继续开发报告终检、保存与成功结算，真实调用继续关闭；沿用社区版隔离执行方向

## 决定

1. 新增内部终检服务，不给现有 API、Agent worker 或命令注册自动执行入口。默认关闭；开启内部测试时也必须显式提供版本化的蕴含及语义纯校验函数，没有生产默认通过实现。
2. 输入只能来自已有预算预留、隔离响应和连续检查点，末阶段必须是绑定当前终检策略的 `judge`。每个预留都必须有对应检查点，存在未知/未完成操作不得成功。不能用 Agent 元数据回执直接交付。
3. 首版只接题材 L1 的保守引文档案：四个固定章节各至少一条不同的逐字引文；仅接受 AI 抽取引文节点，拒绝自由句、模板参数、自报人审公司行、行情、节选与人工转载放行字段。其他级别/节点先拒绝，不据此声称完整 L1/L2 已实现。生产最小可交付政策仍须确认。
4. 初读后在事务外完成结构、证据、蕴含和最终可见文字的语义校验；最终写入前重新当前读租约/取消/期限、完整检查点、题材及来源。来源按编号有序加锁，授权副本必须与当前登记一致且有效；正文、偏移、哈希、链接、来源类型和采集时点逐项复核。不得把字符串共现当作语义蕴含充分证明。
5. `tm_ai_report_commits` 保存不可变终检提交收据：成功才含报告 JSON；拒绝只留策略、摘要、封闭判定及原因码，不保存候选正文。复用原 `FinalizeInTx` 和失败释放路径，报告/收据、任务终态事件及积分终结同事务提交，任何故障整体回滚。金额只取原冻结锁价，不接受补扣金额。
6. 重放复核原阶段/策略、收据、任务与冻结/终结流水，不重新执行校验或结算；异配置拒绝。提交回执不明返回空结果，按原任务查询/重放，不换键。取消与成功由账户/任务锁串行裁决；来源或纯校验的明确拒绝全额释放，数据库/上下文不明保留现场，由原取消/到期路径处理。

## 边界与验证

新增迁移仅在全新可丢弃库验证；不自动修改生产表。真库覆盖 RC/RR 的成功/拒绝、同键重放、竞争、来源撤回、旧围栏、取消、未知提交以及终检收据/任务事件/账务故障回滚。另做回滚结构探针与受限账号反例。模拟判定不证明真实模型质量、语义拦截率、费用或授权，会员报告读取仍不可用。
