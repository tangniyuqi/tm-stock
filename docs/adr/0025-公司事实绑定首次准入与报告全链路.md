# ADR-0025：公司事实绑定首次准入与报告全链路

## 背景

ADR-0024 的准备核尚不参与报告。直接把含整份准入的候选摘要写回准入会循环依赖；仅在终检时查询公司又无法证明首次批准范围。

## 决定

1. 保留原四节引文政策及其编码/摘要。新增显式公司报告政策，前三节为编号回取引文，披露公司节为完整资料库公司集合，不接受模型增删、改写、排序公司。无公司时不能用该政策交付；不伪造空事实。
2. 在原候选完整绑定摘要之外增加独立事实摘要，绑定用户/题材、全部原材料身份、审核映射与主数据，不包含整份执行摘要。准入和报告政策均保存此摘要；执行计划继续通过原完整摘要绑定。缺摘要、旧任务或矛盾计划不得降级使用公司政策。可选空字段省略，旧准入及计划的规范编码不变。
3. 转换两次读取、终检判定前及最终提交事务、会员报告两次读取均共享当前来源/快照/公司行后重建事实摘要。撤回、增删、停用、改审核或主数据都不允许按旧集合发布；依赖故障保留现场，已知证据失效走原失败释放。成功后撤回仅拒读，不改写历史结算；终态收据重放不补调用。
4. 公司材料即使未被前三节引用，也必须纳入证据读取及蕴含输入。语义输入须含公司名称、代码、环节、依据和节选标记，不得因数据行没有Text而漏检。不把审核人、许可归档、账户身份发给模型或会员。
5. 复用原双判定、最终报告/成功事件/积分结算事务和本人读取；无新增公开执行入口、DDL、默认生产放行或付费调用。DTO及前端只扩展客观公司行与出处，仍无个股详情或行情假值。

## 后果

该政策是开发契约，不是已获生产最小交付、模型质量或法律验收。真实调用、公开收费及部署继续关闭；完整L1其他内容质量、L2、实际H5验收及外部授权关口保持开放。必须以显著示例来源和测试模型服务完成正反例，不能把模拟判定放进生产。
