# ADR-0026：会话主入口与受限自然语言资料问答

## 背景

现有会员AI页围绕报价、任务、报告和反馈开发；归档协作者另有会话/技能/SSE页面，但没有配套后端，模型delta直出与当前终检/账本契约不兼容。将两者视为只能二选一会丢失完整助手体验；整包覆盖又会破坏已验证链路。

## 已确认决定（2026-10-21）

1. 用户设置的持续目标是以会话为主入口，整合资料问答、技能、多Agent资料整理、报告和反馈。优先逐项适配归档的界面和交互，不整体替换当前入口、后端或组件库。
2. 用户进一步确认：首版可输入自然语言，检索范围限选定题材/专题的获授权资料和本人可读报告；答案只含可追溯引文及固定模板，无证据则拒答，不自动联网、不提供投资意见。此项取代旧的“整个助手没有自由文本输入”假设，但不放开不受约束的问答或证券评价。
3. 原收费任务的输入、锁价、幂等、冻结、终检、结算及失败释放不变。会话只关联任务；聊天不逐条直接扣分，重新生成报告必须另行报价确认。问答的模型预算和使用配额由服务端限制，正式额度/价格未确认不得公布或上线。
4. SSE只传公开任务进度，保留原JSON事件和轮询兜底；H5用标准Bearer fetch流，不引入URL令牌、Cookie兼容放行或模型原始token直播。报告可见性仍由原报告服务核验。
5. 仅本地隔离开发验收，不部署、不动真实用户积分、不启生产模型开关；原L2质量/授权和发布门槛不因本决定而视为满足。

## 备选与后果

- 只保留报告任务页：省去会话工作，但不满足用户已确认目标，拒绝作为最终交付。
- 原样启用归档聊天：可复用视觉，但缺后端、权限和证据/计费保证，拒绝。
- 在既有链路上增加会话和受限问答：采用；新增输入注入、历史授权失效、任务关联恢复、流连接资源等风险须独立测试。

需求/验收单一来源为`docs/specs/ai-analysis/requirements.md`第0节；技术契约见同目录`design.md`第12节，测试与阶段状态见`tasks.md`第11节。本决定不是功能已实现、已获法律复核或获准上线的声明。
