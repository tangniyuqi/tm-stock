# ADR-0017：编号选择转换为报告候选

状态：开发实现，真实调用与公开发布关闭。

## 背景

ADR-0016 的终检核接收可信内部候选，但隔离的 Agent 研究正文不能直接成为候选。现有 L0 归属抽取只有公司、题材与业务谓词，不能把这些条目自动解释为题材定义或事件时间线。

## 决定

增加独立的报告编号选择契约，不修改 L0：模型只能输出章节枚举、快照编号、连续句子编号。来源集合及题材由可信装配方提供，输入摘要绑定完整快照、授权副本、任务、公示及最终校验策略。模型自写文本、偏移、链接、来源标题和“已核验”字段全部拒绝。

代码按编号逐字回取连续原文，注入可信出处与公示，按快照编号/原文位置排序，形成既有 `Proposal`。重复或重叠句子、不完整章节、部分坏条目、超长与禁用内容整份拒绝，不节选补救或生成占位内容。结构正确并不证明章节蕴含、时间关系或公司身份正确，最终两个校验器仍必须通过。

内部 `AIReportService.Convert` 只从原任务已保存且已完成的 `extract` 检查点读输入。转换前后复核会员、任务、当前租约、取消、步骤键/摘要/策略及全部候选来源当前授权、题材。候选正文不序列化到 API 或日志；转换不调用模型、不追加预算/响应、不结算、不发布。下一个 judge 的输入摘要绑定完整前序检查点，不绑定当前 owner/fence，允许新租约复用原捕获结果。

## 后果与边界

- 不增加数据库表或公开入口；复用已有阶段、来源共享锁与终检原子事务。
- 新编排必须分别为抽取/终检持有预算和调用证明；转换本身不算实际调用或实际用量，测试预留仅为预算上界。
- Convert 返回的候选可在最终提交前失效，不能当发布许可；Finalize 必须再次复核来源及双判定。
- 此契约与接线可由明确的模拟响应验证；生产选择器、蕴含/语义质量证明、全任务编排、会员报告读接口及页面仍需后续实现，真实调用保持关闭。
