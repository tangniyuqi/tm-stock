# ADR-0012：阶段结果先隔离，校验后原子推进检查点

状态：开发决策；无公开结果、真实模型调用或收费。

## 背景

ADR-0011 的保守预留只能证明预算已占用，不能证明远端响应已收到或可复用。把预留直接当阶段成功会丢失结果；只保存进度而不保存校验绑定，会让恢复重发未知调用或复用已变化的输入/策略。

## 决定

采用两阶段存储，不增加自由文本公开出口：

1. `Capture` 将脱敏后的阶段响应保存到不可变内部隔离表，绑定任务/用户、预算预留、阶段编号/类型、输入摘要、原始 owner/fence 与内容摘要。仅允许 `collect/extract/judge/agent_call` 外部操作，必须对应同一租约的预留。体积最多 256 KiB，严格 UTF-8/JSON 对象、无重复键、深度至多 32；这些只是结构检查，不是事实或合规通过。纯代码步骤暂不落这种外部结果表，后续可安全重算。
2. `Complete` 在不持数据库事务时调用服务端固定策略的纯校验器（必须尊重上下文、不得发网络请求）；再次锁任务、复核租约/取消/期限、输入、隔离内容摘要和策略后，插入不可变检查点。SQL 在同一事务内推进 `current_step`、分配事件序号并插入白名单 `step_completed` 事件。任一步失败全部回滚；阶段完成不等于任务成功，不结算积分。
3. 新 worker 可以读取已保存响应继续校验，或在输入、结果、策略摘要及事件都匹配时复用已完成检查点；校验策略变更拒绝旧检查点复用。旧 worker 的捕获/完成被围栏拒绝；仅有预留、没有隔离响应时仍是未知结果，不能自动重发。已有检查点和隔离结果均不可覆盖或删除。

初始化/并发遵守 ADR-0011 的空区间锁经验：写隔离结果先 INSERT，仅将明确 1062 解释为已存在，再当前读核对；阶段推进已由任务行锁串行，未完成阶段不先锁不存在的检查点。编号最多 64，不能跳过或回退；每个预留最多对应一份隔离结果和一个完成检查点。

## 边界与代价

- 隔离内容永不进入 C 端 DTO、进度事件、归属表或报告；JSON 隐藏正文且常见格式化输出脱敏。调用层仍须处理凭据/来源/留存授权，结构校验不能保证识别未知秘密。
- 校验策略从内部构造配置提供，复制后固定，不能由用户请求声明“校验通过”。本地伪校验器只用于测试存储事务，不证明真实模型或事实准确性。2026-10-16 增加 `pipeline.NewExtractionStage` 确定性抽取策略：复用既有守卫，整份非空且无拒绝/重复/节选才可推进；来源类别限定事实谓词，输入/实际词表和句式/算法版本/规范化词汇均绑定摘要。它不是语义蕴含、主数据或当前授权证明，其他阶段与完整流水线仍须独立接入、评估；细则见 design.md 3.2.6。
- 复用检查点不替代报告生成前的当前来源授权、证据、红线和公示复核。报告可用仍为 false，不增加收费、报价或成功终态入口。
- 新迁移给任务增加阶段初值/推进保护，旧版可以直接改步骤的探针须改成真实抢占不推进步骤；内部 `ai-task-check` 要求新增两表。生产迁移、权限、完整 worker 崩溃恢复及容量仍需另验。
