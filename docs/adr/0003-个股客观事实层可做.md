# ADR-0003：个股可做，但只到「客观事实层」

- **状态**：已采纳
- **日期**：2026-07-30
- **取代**：[ADR-0002 一期不含个股](0002-一期不含个股.md)（已废弃）
- **相关**：`.claude/agents/compliance-redline.md`（v2）
- **决策人**：董事长

## 背景

ADR-0002 采纳了"方案 C：一期完全不做个股"，理由是"题材 → 产业链 → 个股"这条漏斗
终点落在具体证券上。**该判断过严，现予推翻。**

ADR-0002 自己就写明了代价：

> **产品吸引力显著下降**：剩下的内容接近大厂免费层已有的东西

即：当时已识别出"这个方案会掏空产品核心价值"，却仍选择了它。这是一次**风险规避过度**的
误判——用确定的产品失败，去换取一个并不存在的合规收益。

## 推翻的理由

### 1. 法条判定的是「意见/建议/预测」，不是「是否出现个股」

证监会公告〔2012〕40 号第二条四项要件的核心动词均为**规范性表述**：
投资分析**意见**、**预测**走势、选择**建议**、买卖时机**建议**。

"A 公司主营业务含光刻机零部件"是**事实**；"A 公司今日涨 3.2%"是**事实**。
事实陈述不是意见、建议或预测。

### 2. 行业实践

同花顺、东方财富、雪球、新浪财经、和讯等均展示"概念板块 → 成分股 → 涨跌幅"，
其中包含无投顾牌照的财经资讯主体。这属于**行情与分类信息服务**。

### 3. 产品侧：题材下关联个股是这个产品存在的理由

用户要的就是"这个题材涉及哪些公司"。砍掉它，产品不成立。

## 决定

**一期做个股，但严格限定在「客观事实层」：**

### ✅ 做

| 内容 | 约束 |
|-----|------|
| 题材 → 产业链环节 → 成分股（名称） | **归属依据必须可溯源**（见下） |
| 个股**准实时/延时涨跌幅** | 须有合法行情数据源授权；明示延时口径 |
| 按客观字段排序筛选 | 涨跌幅、成交额、市值、代码 |
| 环节层、题材层涨跌幅统计 | 标注加权口径与来源 |

### ❌ 不做

| 内容 | 原因 |
|-----|------|
| **个股详情页**（基本面、财务、K 线、技术指标） | 最接近"投资分析意见"，一期整体不做 |
| 价值评价标注（龙头/最受益/纯正度） | 落入要件一 |
| 按主观评价排序打分 | 落入要件二 |
| 预测、择时、目标价、投资评级 | 落入要件一/三 |
| 无客观依据的高亮/置顶/首推 | 变相推荐 |
| 个性化个股推荐、异动触发推送 | 落入要件二/三 |

## 🔑 核心约束：分类依据可溯源

这是本决策**能否成立的前提**，不是可选项。

平台决定"把哪家公司挂到哪个环节"，若依据是我方主观判断，就退化为**品种选择**（要件二）。
因此：

1. 每条「题材 ↔ 个股」映射**必须存证据字段**：
   `source_type`（公告/年报/招股书/官方目录）、`source_excerpt`（原文摘录）、
   `source_url`、`collected_at`。
2. 详情页**可展示依据**（点"依据"看到原文摘录与出处）。
3. **无依据禁止入库**——宁可少收录。
4. 排序只按客观字段。

> 副作用是正面的：**可审计的题材库**正是免费产品给不了的东西，即护城河本身。

## 新增识别出的硬约束：行情数据授权

展示个股涨跌幅 = 使用交易所行情数据，**商用须授权**，与投顾牌照是两件事。

- 一期采用**延时行情**（授权门槛与费用远低于实时），页面明示延时口径
- **禁止**用抓取免费网页接口（新浪/腾讯/东财）支撑正式产品
- 合同落地前，开发期只能用**明确标注的模拟数据**

## 后果

**正面**
- 产品核心价值回归；G1 验证的是真实产品而非阉割版
- "依据可溯源"同时构成合规抓手与护城河

**负面（必须正视）**
- 合规责任从"结构性规避"转为"**逐条文案与依据的持续管控**"，运营成本更高
- 依据采集是**重人工**工作，直接决定题材库能做多大多快
- 新增行情数据授权成本（年费）
- 本决策仍**依赖持牌证券律师书面复核**（GOALS G3），律师意见与本文冲突时以律师为准
