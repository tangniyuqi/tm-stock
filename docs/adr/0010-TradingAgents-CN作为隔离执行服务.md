# ADR-0010：TradingAgents-CN 作为隔离执行服务

- **状态**：已采纳服务复用方向；本地实现、模拟契约验证及独立依赖安装已授权，完整服务当前不启动，真实付费联调和生产启用待确认
- **日期**：2026-10-15
- **版本选择补充（2026-10-16）**：用户明确选择社区版。现有固定提交本身即为社区版，继续以它为开发/测试协议参照，不切换 Pro、不复制受限应用代码，也不自动启动完整服务或真实模型。
- **决策依据**：用户明确要求“调用他的给我们的项目服务”，后续要求完整推进，并授权“安装依赖，如果本地部署不能解决问题就不本地部署”
- **相关**：[ADR-0008](0008-AI分析模块起步方式与存量整改.md)、[设计](../specs/ai-analysis/design.md)、[操作手册](../specs/ai-analysis/internal-review-runbook.md)

## 背景

此前设计仅借鉴 Agent 模式，不引入外部执行服务。用户现在明确选择实际调用 TradingAgents-CN。此变更不放宽“不评价、不预测、不荐买卖、依据可溯源”的公开输出边界，也不取代现有 L0 单来源、无工具、人审流水线。

核对版本为 `hsliuping/TradingAgents-CN@51060a7682cf51810b4bc3a704829438d18cd8dc`。其 [V2 异步分析接口](https://github.com/hsliuping/TradingAgents-CN/blob/51060a7682cf51810b4bc3a704829438d18cd8dc/app/routers/analysis.py) 提供提交、状态、结果与取消；智能助手规划接口不是同一契约。调用多 Agent 分析不能伪装成现有单模型 Chat Completions Provider。

## 决定

1. 本项目继续以 Go/MySQL 管理身份、任务、账本、证据与公开报告；上游独立进程/数据库部署，通过服务器间 API 调用，不迁移本项目到 Python/MongoDB，也不复制上游应用代码进本仓库。
2. 新增独立 `internal/agents/tradingcn` 适配器、内部执行登记与 `cmd/ai-agent`。第一步接 V2 异步任务，不冒充已经完成公开 L2。固定模型与有限分析师由服务器配置；不开放自由提示词、任意工作流覆盖或用户提供的远端地址。
3. 提交前持久预留请求和配置限额；同请求异身份/异载荷/异配置冲突，同请求重放不再提交。入队后异常可能返回 400，因此所有提交失败保守记为未知，不自动重试。限额是“提交次数”，不是远端 LLM 调用次数、token 或金额上限。
4. 取消先持久登记且最多发送一次；受理回执不等于模型或工具已停止，须查询远端状态。未知提交与崩溃中断不自动补交，不通过创建新请求编号规避核对。
5. 上游正文只能脱敏后进入隔离表，内部命令只输出状态与摘要；不得直接发布、作为归属依据入库、或驱动会员扣积分。上游 `tokens_used` 有回退默认值，不能据此声称掌握真实账单用量。
6. 默认关闭。普通模式只允许精确批准域名 HTTPS；显式本地评估模式仅允许字面回环 IP、明确端口的 HTTP。禁止代理、Cookie、跳转、自动登录和令牌刷新；该例外不允许公网或内网 HTTP 地址。

## 授权与上线边界

上游 [LICENSE](https://github.com/hsliuping/TradingAgents-CN/blob/51060a7682cf51810b4bc3a704829438d18cd8dc/LICENSE) 区分 Apache-2.0 目录与专有的 `app/`、`frontend/`、根目录 `core/`。完整 API 服务涉及后者；本地运行或 HTTP 调用不能推导出商用许可。个人/评估用途和商业服务的适用范围需人类确认；配置中的批准引用只是追溯信息，不是对许可真实性的技术认证。

真实联调仍须确认独立服务地址、使用许可、模型与来源的评估批准及成本限额。公开接入还缺远端可强制预算、受控来源/工具、真实用量与版本证明，以及本项目证据转换、终检、报告、成功结算和会员页面闭环。接口模拟和隔离 MySQL 验证不证明真实多 Agent 质量、费用或商用合法性。

固定提交的社区版授权实现不连接软件授权服务器、不验证软件激活令牌；不需要另购激活码才能做许可允许的个人使用/评估。该事实不免除 API 登录认证、模型 API 密钥和数据源权限，也不等于社区版包含 Pro 功能。`TM_AI_AGENTS_TOKEN` 是服务登录 Bearer；`TM_AI_AGENTS_LICENSE_REF` 是适用许可与用途的追溯引用，不是软件序列号。选择社区版不被记录为已取得网站对外服务的商业许可。

`ai-agent version` 只输出本适配器固定的社区版协议参照及上述认证区别，不读取标准输入、环境配置或数据库，也不探测远端。`remote_version_verified=false` 明示它不是部署证明。不修改既有 Profile 摘要编码，避免把描述元数据变化变成持久请求配置迁移。

## 后果与回退

关闭执行开关即可停止本工具新的远端操作，`show` 仍可本地查询；已入队远端任务不会因此自动停止，必须按原配置和远端编号人工核对。新增表独立于账本和共用会员资产表，迁移须先在隔离库验证；不删除执行/审计记录来重置限额。上线站点与当前工作区版本存在差异，部署前须确认实际构建来源，不能直接覆盖。
