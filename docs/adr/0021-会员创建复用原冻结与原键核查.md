# ADR-0021：会员创建复用原冻结与原键核查

- 状态：开发中；真实执行、对外收费、生产部署继续关闭。
- 背景：已有任务事务核能原子冻结/建任务；不能为了接HTTP重复实现账务，也不能在响应未知后换键创建。

## 决定

1. 会员报价与创建独立默认关闭。请求只有既有契约的任务类型、主体类型/编号、创建时的价格版本；用户身份来自当前会员JWT，创建键只取单个标准Idempotency-Key头。不接受积分金额、预算、模型、URL、批准标记或自由问题。
2. 新创建必须由可信服务端控制器提供并复核当前价格/资源上界、主体与授权资料范围、模型公示/质量及远端硬预算引用。格式校验不是这些证明的实现；没有生产默认通过控制器，没有价格占位或固定报价。当前只允许已有执行核支持的题材L1新建，其余返回不可用，不冻结后等待一个不存在的执行器。
3. 报价只读，按数据库UTC、当前账户与实际可用批次计算可消费积分，不把未清扫的账面余额当可消费额。它不保证稍后创建仍有余额或同价，不产生冻结、事件或模型调用；当前批准在事务外前后核验，不持锁等待远端。
4. 创建先按原用户/原键核查原请求。已确认同键同体返回原不可变创建收据，即使价格/准入已变化也不重新报价或冻结；同键异体40903。新请求准入通过后只调用原AITaskService.Create，仍由同一事务锁账户、查重、冻结、建任务和首事件。并发竞争最后由原事务核裁决。
5. 增加独立只读创建收据查询，只接受Idempotency-Key头和当前会员身份；仅返回原任务编号、原锁价和价格版本。不含原键、内部任务号、冻结单、用户编号、提示词或预算。它不依赖模型/来源批准仍有效，不宣称任务完成或报告可用。读取原任务、原冻结与原冻结流水，不以一行任务记录冒充完整创建证据。
6. 任何提交/依赖未知均返回空收据和固定错误；客户端只能查询原键或原任务，不自动重发、不换键。独立收据查询可在新建停止时继续服务，但不能打开新的创建路径。本人以外与不存在同为404，响应no-store。
7. 会员页面复用既有题材搜索，只允许选择返回的题材并请求L1报价。展示服务端价格、实际可消费积分、时点及资料范围，显式确认后才创建。发送前持久保存原键与最小请求信息；本机存储失败、安全随机数或跨页签互斥不可用时不发送。当前H5用Web Locks协调同账号页签，已有待核查请求时不另建。JWT的ID仅作本地存储分区，绝不用于服务端身份或准入判断；不另存令牌、报告或来源正文。未知结果、离页及重载保留原键，核查404也不推断原请求绝不可能提交，不据此自动清除或换键。不同账号不展示前账号收据。

## 后果与验证

报价/收据会短暂按既有账户锁序读取，不能冒充无锁或仅SELECT权限。审批与数据库不能构成分布式原子事务，创建只做当时准入；后续执行/报告仍必须重新核验授权，撤回不能被创建收据绕过。实际价格簿和批准控制器的来源仍须可信实现，不将接口、摘要格式或测试控制器当生产证明。

验证范围：关闭/缺证明零冻结；当前JWT/会员与身份隔离；严格请求、真实可用批次/价格变化、同键与并发创建；事件故障整体回滚；真实提交后回执未知→原键核查→单次冻结；再接已有模拟CN/双判定/报告/结算及报告读取。MySQL8/9与前端分别取证，未验证前不标完整闭环完成。
