# ADR-0024：报告公司事实只读复用已审核资料库

## 背景

L1 的披露公司不能由外部 Agent 选择或生成。现有报告终检只支持四节引文，尚缺资料库公司行；既有渲染器已有封闭的 `StockRow` 和 `library` 来源性质。

## 决定

1. 在现有报告服务中增加内部只读准备方法，复用账户→任务→来源→快照→题材锁序和首次准入记录，只读取当前已审核、启用、未删除的题材及直接产业链环节映射，不新增接口、命令、后台任务或执行开关。
2. 同事务取得主数据、审核人/时点、依据及当前授权快照。依据必须与首次批准材料的链接、类型、采集时点一致，且为该不可变快照的连续原文，包含公司名称。主代码与冗余代码不一致、审核留痕不完整、证据不匹配时整批拒绝，不能静默筛选。
3. 最多32条映射，查询第33条用于判定超限；超限整批拒绝，不截取前32条。按证券代码、环节编号、映射编号确定性排序，忽略人工排序及模型判断。不把空集合伪装成有公司数据；最小可交付标准仍由报告政策决定。
4. 复用数据行结构，保留节选标记；没有行情授权，不填行情值。候选的摘要绑定首次准入、全部映射和对应快照身份，只在确认事务提交后返回，不产生账务、步骤或报告写入。
5. 该准备结果不是发布或结算许可。现有四节引文政策继续拒绝公司行；完整L1还须把公司集合绑定到执行计划、转换、双判定、终检及读取的重新核验，再接展示，不能凭此ADR宣称完整报告已交付。

## 选项及后果

不采用外部 Agent 自选公司、按相关程度排序或仅凭来源域名相同即复用依据。只读准备可在真实调用关闭时用示例资料验收；缺失实际授权、语义质量和正式交付政策的关口保持关闭。无共表DDL或上游迁移。

查询复用资料库现有主键、`idx_theme_audit` 及上游父节点条件。33行上限仅限制结果，不证明扫描行数、共享锁数量或排序成本有同样上限；正式接线前须在经批准的代表性数据副本上检查执行计划与锁等待，不擅自给上游表加索引。候选准备核的双版本示例测试不替代此容量验收。
