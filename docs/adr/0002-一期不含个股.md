# ADR-0002：一期不做个股（方案 C）

- **状态**：已采纳
- **日期**：2026-07-29
- **相关**：`.claude/agents/compliance-redline.md`

## 背景

原始产品设想中，题材焦点/动态/题材库的详情页都要展示**成分股、股票列表与个股涨跌幅**，
这也是产品最"值钱"的部分（用户最想要的就是"哪些股票和这个题材有关"）。

但监管对"荐股软件"采**功能实质测试**：具备"对具体证券分析评价 / 预测走势 / 选择建议 /
买卖时机"任一功能，即属须持牌的证券投资咨询业务。经从严评估：

- "题材 → 产业链 → 个股清单"这条漏斗，终点落在**具体可交易证券**上；
- 平台还要决定"哪些公司挂到哪个环节"，这本身就是**品种选择**；
- 叠加会员付费，构成"直接或间接获取经济利益"要件；
- **免责声明不能豁免**（结构违规时反成"明知故犯"证据）；
- 证券投顾牌照 **2016 年起停发**，自建持牌无出口。

## 候选方案

| 方案 | 做法 | 合规风险 | 产品代价 |
|-----|------|---------|---------|
| A 完整客观镜像 | 个股 100% 来自权威第三方分类，中性排序、无榜 | **高**（终点仍是个股） | 低 |
| B 降级为附注 | 个股不可筛选/排序/关注，仅环节下静态附注 | **高**（终点未变） | 中 |
| **C 一期不上个股** | 漏斗止于题材/行业/产业链环节层 | **相对可控** | **高** |

## 决定

**采用方案 C**：一期完全不做个股。

- 查询止步于**题材 / 行业 / 事件 / 产业链环节**层
- 不存储、不展示个股代码、名称、涨跌幅
- 事件只关联到题材层，不做事件驱动选股
- 个股能力整体后置到二期（须收购牌照或与持牌机构实质合作）

## 后果

**正面**
- 从根本上规避"具体证券品种"这一构成要件，H2/H3/H5/H6 类风险随之消解
- 不把产品核心押在"题材层≠证券"这个**未经律师验证**的假设上
- 一期备案负担大幅降低（免 App 备案、免经营性 ICP、免证券牌照）

**负面（必须正视）**
- **产品吸引力显著下降**：剩下的内容接近大厂免费层已有的东西
- 因此 G1「验证有没有人为安全版付费」成为**先决条件**，而不是做完再看
- 二期要上个股，只能走收购牌照或持牌合作，成本与周期都高

## 落地约束

- 词表 `scripts/compliance-forbidden-words.txt` + `check-compliance-words.sh` **机器守护**
- 数据模型层面：一期**不建**成分股实体（见 `.claude/agents/domain-glossary.md`）
- 本决策的最终确认**依赖持牌证券律师书面意见**（见 GOALS.md G3）
