# ADR-0019：Agent 线索受限选择与固定 L1 编排

- 状态：开发实现，未提交/部署；真实调用关闭。
- 背景：Agent 隔离回执、授权编号转换、双判定和结算核原先分离，不能证明新任务可走完主链路。

## 决定

1. `agents.PayloadReader` 仅供内部编排读取隔离终态，仓储验证操作人、原请求、不可变事件与正文摘要，不新增 HTTP 原文接口。`agenttask.Hint` 绑定任务及原计划，研究原文只是可疑线索，最多256KiB；重复键、过大或身份错配整份拒绝，不截断。
2. 选择器请求只含题材、线索和授权快照的编号/哈希/句子；不发送来源许可归档、账户或会员资料。输出仅四节出处和连续句子编号，正文仍由代码回取。响应先捕获，实际模型/用量/回执不符或编号非法不出候选，不伪造成功。
3. 选择和蕴含/语义使用同一个封闭计划的单次调用协议：原任务预算内先持久预留，新预留才能发送，必须有当前准入及前后持久审计；响应未知不补发，已有隔离响应允许有效新围栏完成。无生产控制器、公开入口或自动装配。
4. `AIL1ReportWorker` 固定步骤：Agent1 → 选择2 → 蕴含3 → 语义4（蕴含不通过则省略）→ 本地候选 → 原 `Finalize`。本地候选的调用/token预留只是原核要求的保守容量，不认定实际模型使用。规划器/两个控制器缺失或关闭时不访问网络；源/质量/硬预算实际证明不能由非空引用替代。
5. 原独立 Agent worker 保持单操作约束；新增 `RunOwned` 只用于完整编排固定第一步，使用 `ReserveStep(1)`，后续步骤存在时只复核原前缀，不重新提交。最终提交前先停止并等待心跳退出，再续足至少一分钟租约；最终30秒纯终检/提交不与自己的后台心跳竞争。

## 后果与验证范围

复用既有原子报告/任务/积分事务、来源共享当前锁及取消/期限机制。确定性拒绝释放，网络/审计/提交未知保留现场；终态重入只给任务元数据，报告可用标记仍为false，不能冒充会员已可读。

2026-10-18补充：规划/执行前后的已知来源拒绝也进入失败闭环，不仅在最终报告校验时释放。先以当前读检查原准入及调用完成证明；有未完成预留时不领取，防止普通领取的尝试耗尽路径掩盖未知调用。仅无未知调用时取得有效围栏，再于同一账户→任务→预算/阶段证明→冻结单事务中重查原准入、完整预留/检查点/事件前缀及原冻结身份，复用原失败/释放/事件写入。没有预留的首次执行可直接拒绝；有任何未完成预留则仅返回`response_unknown`，不补发、不释放、不删除隔离结果。普通404、计划身份冲突、缺配置或依赖/提交错误不能转成已知拒绝；未知提交返回空收据，恢复只核查原任务终态。该门禁不负责判定模型质量，不开放真实执行或收费。

普通恢复没有来源拒绝时也适用ADR-0013的共用失败核查；不是仅在来源拒绝入口保护未知调用。到尝试上限但尚缺原始响应，领取事务不终结或取得新围栏，L1/独立Agent/恢复worker仅返回原任务的未确认状态。直接失败和重试/退避耗尽同样受共用核保护；已捕获响应允许已知失败不等于取得公开报告许可。来源拒绝的完整检查点/事件前缀预查仍保留，不因共用原始响应核查而放宽。

上游确认失败/取消也先按ADR-0015保存专用封闭终态回执和检查点，再由L1原失败事务释放；不能绕过共用未知调用核查。该分支不取研究正文、不调用编号选择或双判定、不保存报告，也不把上游取消冒充用户主动取消。回执/检查点或最终失败提交未知只按原键恢复；旧围栏没有任务回执时统一`response_unknown`，冻结及原预留保留，不补造旧响应。

此路径只覆盖保守题材L1引文档案，不代替完整L1/L2产品最小交付、实际模型质量、来源/上游使用授权、真实远端可强制预算及费用验收。测试服务必须留在测试文件；生产规划与控制器尚无实现。双版本真库、模拟CN与模型、回执未知恢复、并发及页面验收分别取证，不用本地内存测试代替。
