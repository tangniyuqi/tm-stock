# ADR-0005：一期不做「AI 分析」

- **状态**：已采纳
- **日期**：2026-07-30
- **相关**：`.claude/agents/compliance-redline.md` v2、[GOALS.md](../GOALS.md) G1
- **影响**：首页底部 Tab「AI分析」**一期隐藏**

## 背景

设计稿底部 TabBar 为：`首页 / 7x24快讯 / AI分析 / 我的`。
「AI 分析」尚无需求规格。本文决定它在一期的去留。

## 决定

**一期不做，Tab 隐藏（不留空 Tab）。**

## 理由

### 1. 它是唯一一个能"一句话毁掉全局"的功能

本项目其余所有合规控制都是**结构性、确定性**的：
不建个股详情页、不加评价字段、无依据不入库、排序走白名单——
这些要么成立要么不成立，可以被测试断言。

生成模型是**概率性**的。护栏能把"输出一句投资建议"的概率压低，**但压不到零**。
而合规上**一次输出就是一次违规**——它不看概率。

前面所有工作（依据可溯源、不评价、不预测、词表守护）建立的确定性，
会被这一个不确定组件整体拉低到它的水平。

### 2. AI 荐股是监管明确的重点打击区

证监会对利用软件从事证券投资咨询的监管中，AI 输出投资分析意见属重点关注。
「AI 说的」在法律上是**我方的输出**，不是用户自己的判断。

### 3. 备案会成为上线关键路径上的阻塞

面向公众提供生成式 AI 服务需完成：

| 事项 | 说明 |
|-----|------|
| 互联网信息服务**算法备案** | 材料准备 + 审核，周期以月计 |
| **生成式 AI 服务备案** | 面向公众提供时必需 |
| **AI 生成内容标识** | 《人工智能生成合成内容标识办法》要求显著标识 |
| 安全评估 / 语料与输出管控材料 | 需成体系的文档与机制 |

这些**不是写代码能解决的**，而且会把整个一期的上线时点绑在备案进度上。

### 4. 它不服务 G1

G1 要验证的是「有没有人愿意为**题材查询**付费」。AI 不承担这个验证，
却要占用一期最稀缺的时间与合规额度。

### 5. 与「一期 MVP 从简」的定调一致

## ⚠️ 一个看起来可行、但不能选的折中

有人会提：**一期做个"AI"入口，但底层只是从我们自己人工写的题材库里检索并展示原文。**

- 从合规看：纯检索不产生新内容，**确实**不属于生成式 AI，不需要备案。
- 但从诚信看：把**检索**包装成「AI 分析」是**名不副实**，
  涉嫌虚假宣传，也违反本项目的「数据真实铁律」——
  同一条铁律既禁止假数据，也禁止**假称能力**。

**所以：要么别叫 AI，要么别做。不做"叫 AI 的检索"。**

## 后果

**正面**
- 一期上线不被备案进度绑架
- 合规面收敛为可测试的确定性控制，整体风险等级可控
- 省下的时间投向真正的护城河：**题材库与归属依据的采集**

**负面（正视）**
- 少一个"看起来很现代"的卖点标签
- 首页 TabBar 从 4 格变 3 格，需前端调整
- 若竞品都上了 AI，短期观感上会显得保守

## 二期若要做，前置条件（清单化，便于日后直接启动）

1. 完成算法备案 + 生成式 AI 服务备案 + AI 生成内容标识机制
2. **白名单式生成**：只允许基于我方题材库内容复述，不允许自由联想
3. **输出后置过滤**：生成结果强制过一遍禁用词表 + 个股建议检测，命中即拦截不展示
4. **拒答清单**：涉及"买不买 / 什么价位 / 会不会涨 / 哪只更好"一律拒答并给固定话术
5. **全量日志留存**：每次输入输出可追溯（监管问询时的举证材料）
6. 显著标注「AI 生成，仅供参考，不构成投资建议」
7. 持牌律师对护栏设计出具书面意见

> 上述 1–7 **全部满足**才可开启；缺任意一项即不上线。
