# ADR-0015：任务与多 Agent 执行接线，回执不替代报告终检

状态：内部接线开发；真实执行、生产装配、公开报告与收费保持关闭。

## 背景

用户要求接通 TradingAgents-CN，在确认尚无服务/授权/模型/预算配置后选择“先完成接线开发”。现有 V2 适配器与持久执行登记独立于任务租约、预算预留、阶段检查点。固定上游版本仍为 `51060a7682cf51810b4bc3a704829438d18cd8dc`，本地源代码已核对；其 API 输入是股票代码，不是本项目的题材/专题编号。不能猜测两者映射，也不能把上游正文或默认 token 数当成事实报告/真实账单。

## 决定

新增 `internal/ai/agenttask` 与 `AITaskAgentWorker`，复用现有任务、预算、阶段、`AIAgentService` 与 V2 HTTP 适配器。仅支持显式已有任务的第一步 `agent_call`，不是全队列或通用多阶段调度器。没有生产规划器、启动装配、会员入口或新 CLI 开关；选项默认关闭，关闭时在读任务/抢占/预算/网络之前拒绝。测试准入规划器只编进测试二进制。

可信规划器须绑定会员/任务编号、不可变任务编号和主体，并提供主体到股票代码的可信映射、独立内部操作人、执行配置摘要与保守资源上界；Plan/Recheck 还须核对当前来源/许可与远端强制预算。当前 V2 API 未提供所需证明，不能仅把一个批准引用或布尔值填上就生产放行。本轮只交付接口和关闭的接线核，不宣称这一准入已实现。

请求编号与预留键均由会员、任务编号、不可变任务号、固定 `agent_call:1` 域计算；股票、操作人、配置与资源变化不改变这个键，但改变输入摘要，从而与原预留冲突。禁止换键规避未知调用。单阶段预留额外在现有预算事务当前锁内拒绝其他阶段/多项预留，防止把旧抽取任务混作新的外部执行任务；原多阶段 Reserve 行为保持不变。

任务抢占后复用原独立心跳机制，阻塞 HTTP 时也续租，失败取消工作上下文并等待心跳退出。预算确认提交后才查看/提交上游；预算已存在而没有执行登记时视作未知窗口，不能认为“还没调用”再提交。上游提交仍由原持久登记确保最多一次，所有提交异常保守未知；状态轮询有间隔与父期限，不在数据库事务里等待网络。

远端完成先由原 Agent 服务获取、脱敏、隔离。任务阶段仅保存请求编号、远端编号、配置摘要、结果摘要四字段回执，不复制研究原文、默认 token 数或金额。纯回执策略绑定输入和全部元数据，只证明隔离结果身份，不证明事实、授权、语义或公开报告合规。通过检查点后只返回 `evidence_pending`，任务仍 running、冻结不变、报告不可用、不成功结算。

## 失败与代价

- 预算提交未知、Agent 提交未知、缺登记保留 `response_unknown`，不重发、不退款、不清预算。
- 旧租约已预留且远端结果已隔离，但旧租约未捕获任务回执时返回 `capture_pending`；不补造旧围栏响应。已有任务回执则新租约可复核并推进/重放检查点。
- 已确认上游失败/取消先以独立`task_agent_terminal_receipt_policy_v1`捕获请求编号、远端编号、配置摘要和封闭State，再沿原阶段校验/检查点返回`upstream_terminal`，不是任务成功。成功隔离回执的四字段编码/摘要不变，失败回执不能通过成功回执策略或变成研究线索。本接线核不擅自终结或释放原任务，L1编排收到持久确认后才复用共用失败事务。
- 用户取消、心跳/上下文/存储/准入错误返回空候选收据、停止本地工作，不宣称远端停止，不自动发送取消或作成功结算。原任务取消/过期清理、独立 Agent 运维核对继续按既有规则处理。
- 来源/准入复核在阶段事务外；即使事后拒绝也可能留下隔离回执/检查点，它们没有公开效力。报告路径仍需独立、当前授权的最终核验和同事务保存/结算。

双版本验收使用真实 Go HTTP 适配器对明确测试服务、真实 MySQL 任务/执行登记/账本；含固定键重放、混合阶段拒绝、未知窗口、事件故障原子回滚、旧租约无回执、慢提交独立心跳、取消和40并发。该证据不是上游真实服务、真实多模型质量/成本、生产许可/预算准入或全部事务边界杀进程验收。

2026-10-18补充：共用失败核启用未知调用保护后，必须同时保存确认上游失败的阶段回执，否则已知失败也会被当成缺响应而保留冻结。Capture/Complete或提交未知返回空候选，不借内存终态绕过保护；同一有效围栏可复用已保存回执完成后续失败释放。原预留围栏已失效且没有任务回执，仍不补造；L1把独立接线的`capture_pending`归一为`response_unknown`，队列不伪报终结/交付。明确用户取消与实际到期政策不变，没有增加任何真实执行开关。
