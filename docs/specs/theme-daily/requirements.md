# 题材动态（按日）· 需求规格

- **等级**：B（新业务流程，首页第一屏）
- **关联目标**：GOALS.md G1（免费引流层，把用户导向付费的题材查询）
- **状态**：草案，待评审
- **创建**：2026-07-30
- **合规定性**：🟡 **中关注**——不含个股，但**含排序与榜单视觉**，受
  `compliance-redline.md` v2 约束

## 1. 业务背景

「题材动态」是首页第一个 tab，也是用户打开 App 看到的**第一屏**。
它回答一个问题：**"今天（或某一天）市场上哪些题材在动，因为什么事。"**

它本身不是付费点，而是**引流层**——列表免费，点进题材详情页时才触发付费墙
（详见 `docs/specs/theme-query/`）。

## 2. 用户与场景

- **谁**：波段 / 上班族散户
- **什么情况**：收盘后或盘中想快速知道"今天什么题材有动静"；
  或想回看"上周三发生了什么"
- **想达成**：30 秒扫完当日题材动态，对感兴趣的点进去看构成

## 3. 🔴 合规边界

| ✅ 做 | ❌ 不做（红线） |
|------|---------------|
| 事件的**客观标题**（转述或原文转载） | 我方创作带预测/评价的标题 |
| 事件归属的**题材标签** | 事件 → "因此利好这些股"的推导 |
| **题材层**当日涨跌幅（不是个股） | 个股涨跌幅（本页不出现个股） |
| 按**客观字段**排序，且 UI 明示依据 | 按我方"重要性/关注度"打分排序 |
| 序号仅表示列表位置 | "最值得关注 / 今日最强"类文案 |
| 历史日期回看（客观已发生数据） | 未来日期 / 趋势外推 / "明日看点" |

### ⚠️ 本需求特有的风险：榜单视觉

设计稿里序号 1/2/3 用红/橙/黄高亮，这是**排行榜的视觉语言**。
题材层排行的风险远低于个股排行，但仍需守住：

1. **排序依据必须客观且在 UI 上明示**（不能只有我们自己知道怎么排的）
2. 序号旁**不得**出现任何评价性文案
3. 排序依据**不得**是我方主观打分

## 4. 功能需求

### 4.1 日期切换（对应设计稿第一、四张图）
- 顶部：`上一日` | `📅 YYYY-MM-DD` | `下一日`
- 点日期 → 弹出日历浮层，可选月份、可点"本月"、显示已选日期
- **未来日期禁用**（灰显不可点）
- 默认展示**最近一个有数据的交易日**
- 可回看范围：**自数据开始累积之日起**（见 §6 风险）

### 4.2 当日题材动态列表
每条包含：

| 元素 | 说明 |
|-----|------|
| 序号 | 仅表示列表位置；前三位可用视觉强调，但**不得**配评价文案 |
| 事件标题 | 客观标题；第三方转载须标来源、不改标题 |
| 题材标签 | 该事件归属的题材（可点，跳题材详情页） |
| 题材当日涨跌幅 | **题材层**统计，红涨绿跌；无数据显示「—」 |
| 时间 | 事件发布时间 |

- 点**题材标签** → 题材详情页（触发付费墙）
- 点**事件标题** → 事件原文（外链）或事件详情
- 排序：默认按**题材当日涨跌幅降序**，UI 明示当前排序依据，可切换为按时间

### 4.3 空态与非交易日
- 非交易日（周末/节假日）：显示"当日非交易日"空态，
  **不回填最近交易日的数据**（回填 = 假数据）
- 交易日但无动态：显示"当日暂无题材动态"

## 5. 验收标准（可测）

- [ ] **AC1**：进入首页默认展示最近一个有数据的交易日，日期正确
- [ ] **AC2**：`上一日` / `下一日` 可切换，数据随之刷新
- [ ] **AC3**：点日期弹出日历；可选月、可点"本月"；已选日期高亮
- [ ] **AC4**：**未来日期不可选**（灰显且点击无响应）
- [ ] **AC5**：列表每条含序号 / 标题 / 题材标签 / 题材涨跌幅 / 时间 五要素
- [ ] **AC6**：点题材标签跳题材详情页，题材 id 正确
- [ ] **AC7**：UI **明示当前排序依据**；切换排序后顺序正确变化
- [ ] **AC8**：非交易日显示"当日非交易日"，**列表为空且不回填其他日期数据**
- [ ] **AC9**：接口 p95 < 800ms
- [ ] **🔴 AC10（合规）**：页面**不出现任何个股名称、代码、个股涨跌幅**
      （个股只在题材详情页出现）
- [ ] **🔴 AC11（合规）**：序号区域及列表页**无任何评价性文案**；
      通过 `check-compliance-words.sh`
- [ ] **🔴 AC12（合规）**：排序依据为客观字段（涨跌幅 / 时间）；
      接口不接受"重要性/热度打分"类排序参数
- [ ] **🔴 AC13（数据真实）**：题材涨跌幅无数据时显示「—」，**不显示 0、不显示前一日值**
- [ ] **🔴 AC14（数据真实）**：回看历史日期时，展示的是**该日快照**，
      不是用当日行情重算的结果
- [ ] **异常**：接口失败可重试；日期越界（早于数据起始日）给明确提示

## 6. 不做什么（Out of Scope）

- ❌ 个股（本页不出现，个股只在题材详情页）
- ❌ 题材轮动（首页第二个 tab）——**一期不立项，前端该 tab 先隐藏不留空 tab**；
  理由与数据预留见 `tasks.md` §「题材轮动」的处置
- ❌ 事件的"利好/利空"定性
- ❌ 推送 / 订阅提醒（一期不做触发式推送）
- ❌ 未来日期、预告、"明日看点"
