## ⏰ 优先级提示：任务 3 应尽早上线

`theme_daily_quote` 的**数据起始日 = 快照任务首次成功运行日**。
在此之前的历史数据**永远补不回来**（除非另行采购历史行情）。

因此建议：**即使题材库内容还没做完、页面还没开始写，也先把快照任务跑起来攒数据。**
这与 `theme-query` 的任务顺序无依赖，可并行。

## 「题材轮动」的处置（已定 · 2026-07-30）

**一期不立项、不开发；前端该 tab 一期先隐藏，不留空 tab。**

理由：
1. **它在上线时必然难看**——轮动要看的是跨时间的题材表现，
   而快照数据从任务上线那天才开始攒。上线首日只有 1 天数据，做出来是空的。
2. **它不服务 G1**。G1 要验证的是"有没有人为题材查询付费"，轮动不承担这个验证。
3. 董事长已定调一期 MVP 从简。

**但数据要提前备好**：任务 3 的快照按 `(biz_date, theme_id)` 落库，
粒度已足够支撑将来的轮动视图，**将来立项时不必回头补数据**。
这也再次说明快照任务应尽早上线。

> ⚠️ **命名提示**：将来立项时注意，红线禁用词表里有 `轮动到`（预测式表述）。
> "题材轮动"作为**历史表现**的描述性栏目名可以接受；
> 但内容一旦出现"下一个会轮动到 X"就越线了。栏目名与内容口径要一起评审。
