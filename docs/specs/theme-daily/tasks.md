## ⏰ 优先级提示：任务 3 应尽早上线

`theme_daily_quote` 的**数据起始日 = 快照任务首次成功运行日**。
在此之前的历史数据**永远补不回来**（除非另行采购历史行情）。

因此建议：**即使题材库内容还没做完、页面还没开始写，也先把快照任务跑起来攒数据。**
这与 `theme-query` 的任务顺序无依赖，可并行。
