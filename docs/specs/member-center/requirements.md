# 个人中心（登录 · 会员 · 合规入口）· 需求规格

- **等级**：B（承载登录、订阅激活，且是 **PIPL 与"免经营性 ICP"两条合规的落点**）
- **关联目标**：GOALS.md G1（付费转化的最后一环）
- **状态**：草案，待评审
- **创建**：2026-07-30
- **合规定性**：🔴 **高关注**——本页同时承载
  个人信息保护（PIPL）与**"不做在线支付"**两条硬约束

## 1. 业务背景

个人中心看起来是"杂项页"，实际上一期最关键的两条合规约束都落在这里：

1. **PIPL**：一期用手机号登录 → 触发告知同意、收集清单、**账号注销通道**等强制义务
2. **免经营性 ICP**：一期**不做自有在线支付**（董事长已定）→
   那么"用户怎么付钱、会员怎么开通"必须有一个**支付完全发生在 App 之外**的设计

这两条做错，不是体验问题，是**上不了线**。

## 2. 用户与场景

- **谁**：想订阅题材查询的用户；已订阅想看剩余期限的用户
- **什么情况**：在题材详情页碰到付费墙 → 进个人中心开通；或想查会员到期时间
- **想达成**：能开通、能看状态、能注销

## 3. 🔴 合规约束

### 3.1 不做在线支付 —— 兑换码方案

**App 内不得出现任何支付入口**：不出现"立即购买"、不跳转收银台、不接任何 SDK。

采用**兑换码激活**：

```
① App 内：付费墙 → "如何开通" 说明页（纯文字说明 + 联系方式）
                            ↓
② App 外：用户通过站外渠道付款（公众号 / 客服 / 对公转账）
                            ↓
③ 站外：客服或自动化在运营后台生成兑换码，发给用户
                            ↓
④ App 内：个人中心 → "输入兑换码" → 激活会员
```

**为什么是兑换码而不是"客服手动开通账号"**：
- 用户可**自助**激活，不依赖客服在线
- 每个码唯一、可绑定订单、**可追溯**
- 客服不需要接触用户账号本身

**关键边界**：
- ❌ 不得有跳转到任何支付页面的按钮（哪怕是外链）
- ❌ 说明页不得内嵌收款码图片（等同于收银台）
- ✅ 只能是文字说明 + 站外联系方式
- ⚠️ **本方案降低但不消除"经营性"认定风险，须律师确认**
  （已加入 `docs/上线前置授权清单.md` §7 复核重点）

### 3.2 PIPL（手机号登录触发）

| 义务 | 落点 |
|-----|------|
| 告知同意 | 登录前展示隐私政策 + 用户协议，**必须主动勾选，禁止默认勾选** |
| 收集清单 | 隐私政策内列明：收集什么、为什么、存多久、给谁 |
| 最小必要 | 一期**只收手机号**，不收位置/通讯录/设备标识等 |
| **账号注销** | 必须提供**自助**注销入口，且**真删或匿名化**，不是打 `deleted` 标记 |
| 展示脱敏 | 页面显示 `138****8000`；**运营后台不展示明文手机号** |
| 撤回同意 | 注销即为撤回途径；须明确告知后果 |

### 3.3 免责声明常驻

个人中心底部固定："本平台为公开信息聚合与历史数据统计，不构成任何投资建议。"

### 3.4 禁止出现的内容

- ❌ 收益记录 / 战绩 / 胜率 / "跟随收益"（**红线**：承诺收益类）
- ❌ 邀请返利 / 分销（涉其他合规，一期不做）
- ❌ 任何个股相关的"我的自选"

## 4. 功能需求

### 4.1 登录
- 手机号 + 短信验证码
- 登录前：隐私政策与用户协议勾选（**不预勾选**）
- 验证码 60 秒倒计时、防刷限流

### 4.2 个人中心主页

| 区块 | 未登录 | 已登录 |
|-----|-------|-------|
| 头部 | "登录 / 注册"按钮 | 脱敏手机号 |
| 会员状态 | "未开通" | "有效期至 YYYY-MM-DD" 或 "已过期" |
| 试吃额度 | — | "今日剩余试吃 N 次" |
| 兑换码 | — | "输入兑换码"入口 |
| 如何开通 | 可见 | 可见 |
| 协议与政策 | 可见 | 可见 |
| 账号注销 | — | 可见 |
| 退出登录 | — | 可见 |

### 4.3 兑换码激活
- 输入框 + 激活按钮
- 成功：提示新的到期时间，会员状态立即刷新
- 失败区分提示：**码不存在 / 已被使用 / 已过期 / 不可用于当前账号**
- 防爆破：同账号连续失败 5 次锁定 10 分钟

### 4.4 账号注销
- 二次确认，明确告知：**会员剩余期限作废、不退款、数据不可恢复**
- 执行：手机号**匿名化**（不可反查）、清除登录态、订阅记录保留必要的财务留痕但脱敏
- 注销后同一手机号可重新注册为**新账号**（不继承任何数据）

## 5. 验收标准（可测）

- [ ] **AC1**：未登录进入显示登录入口；登录后显示脱敏手机号
- [ ] **🔴 AC2**：隐私政策与用户协议**默认未勾选**；未勾选时登录按钮不可用
- [ ] **AC3**：验证码 60s 倒计时；同手机号 1 分钟内不可重复获取
- [ ] **AC4**：会员状态与到期时间正确；过期后自动显示"已过期"
- [ ] **AC5**：今日剩余试吃次数与服务端一致；次日 GMT+8 00:00 重置
- [ ] **AC6**：兑换码激活成功后到期时间正确延长，付费内容立即可见
- [ ] **AC7**：四种失败情形提示各不相同（不存在/已用/过期/不适用）
- [ ] **AC8**：同账号连续 5 次错误码后锁定 10 分钟
- [ ] **🔴 AC9**：全站**不存在**任何支付入口、收银台跳转、支付 SDK 引用
      （代码层 grep 支付类 SDK 与关键词，零命中）
- [ ] **🔴 AC10**：「如何开通」说明页**无收款码图片、无支付页外链**
- [ ] **🔴 AC11**：账号注销后，手机号在库中**已匿名化**（原号码不可反查）
- [ ] **🔴 AC12**：注销前有二次确认，且明确告知"剩余期限作废、不退款、不可恢复"
- [ ] **🔴 AC13**：运营后台**不展示**用户明文手机号
- [ ] **🔴 AC14**：页面无收益/战绩/胜率类内容；通过禁用词扫描
- [ ] **AC15**：底部免责声明常驻可见
- [ ] **边界**：网络异常时激活失败不扣码；重复提交同一码不重复延期
- [ ] **异常**：验证码服务不可用时给明确提示，不白屏

## 6. 不做什么（Out of Scope）

- ❌ **App 内在线支付**（红线：会触发经营性 ICP）
- ❌ 第三方登录（微信/Apple）——需额外资质与 PIPL 条款，一期不做
- ❌ 邀请返利 / 分销 / 拼团
- ❌ 收益记录、战绩、胜率（**红线**）
- ❌ 自选股 / 个股关注
- ❌ 头像、昵称、个人资料编辑（一期不收集非必要信息）
- ❌ 消息中心 / 推送设置（一期不做推送）
