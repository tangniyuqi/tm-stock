# 快讯列表与全文搜索 · 需求规格

- **等级**：B（新业务流程 + 外部数据源）
- **关联目标**：GOALS.md G1（验证阶段的免费引流入口）
- **状态**：草案，待评审
- **合规定性**：客观信息聚合，**不含个股、不含评价**，属安全区

## 1. 业务背景

快讯是一期**免费引流**入口：用户不付费也能用，用它换取打开频次与留存，
再向付费的「题材查询」转化。它本身不产生收入，但决定日活。

## 2. 用户与场景

- **谁**：波段 / 上班族散户（一期主要人群）
- **什么情况**：盘中或收盘后想快速扫一眼"今天发生了什么"；或想查某个关键词的历史消息
- **想达成**：30 秒内扫完当日重要信息；能搜到过往某条消息

## 3. 功能需求

### 3.1 快讯列表（pages/news）

- 倒序展示快讯流，字段：**时间 · 正文 · 来源**（+ 可选题材标签）
- **自动刷新**：30–60 秒一次；新内容插入顶部并提示"N 条新消息"
- 下拉刷新、上拉分页（每页 20 条）
- 点击条目：有原文链接则跳原文，无则展开全文
- 列表项文本超长折叠，可展开

### 3.2 全文搜索

- 搜索框入口在列表顶部
- 关键词搜索历史快讯，命中词高亮
- 结果按**相关度 / 时间**可切换排序
- 输入防抖 300ms；空结果显示引导文案

### 3.3 数据来源与刷新策略

- 快讯来自**第三方源**，后端统一接入并落库，前端只调本平台接口
- 后端按固定周期拉取增量，去重后入库
- 全文检索一期可先用 MySQL，数据量上来后切 Meilisearch（**接口契约不变**）

## 4. 验收标准（可测）

- [ ] **AC1**：列表默认加载 20 条，按发布时间倒序，字段含时间/正文/来源
- [ ] **AC2**：页面停留 60 秒内至少触发 1 次自动刷新；有新数据时顶部出现"N 条新消息"提示
- [ ] **AC3**：下拉刷新返回最新数据；上拉加载下一页且**不重复、不跳条**
- [ ] **AC4**：搜索"任意常见词"能返回结果，命中词高亮；结果可按时间/相关度切换
- [ ] **AC5**：搜索无结果时显示空态文案"没有找到相关快讯，换个词试试"
- [ ] **AC6**：列表接口 p95 响应 < 800ms（100 条以内数据集）
- [ ] **AC7**：每条快讯**显示来源**；有原文链接的可跳转
- [ ] **边界**：空数据（首次无快讯）显示空态；单条正文 >500 字正确折叠；分页到底显示"没有更多了"
- [ ] **异常**：接口失败显示错误态 + 重试按钮，**不白屏**；断网后恢复能自动重连
- [ ] **合规**：列表与搜索结果中**不出现个股名称/代码/涨跌幅**；不出现禁用词
- [ ] **性能**：连续自动刷新 10 分钟不出现内存持续增长或卡顿

## 5. 不做什么（Out of Scope）

- ❌ 个性化关键词推送（二期候选）
- ❌ 快讯的评论、点赞、分享
- ❌ 快讯与个股的关联展示（**合规红线**）
- ❌ 快讯情绪/利好利空标注（**合规红线**）
- ❌ 付费墙（快讯一期全免费）

## 6. 前置风险（阻塞项）

> 🔴 **第三方快讯源的商用授权未落实**——这是**上线前置阻塞**，不是技术问题。
> 未取得授权前：只做技术链路打通与自采公开源（政策原文、交易所公告），
> **不得整段转载第三方内容**；只抽事实要素 + 标来源 + 跳原文。
> 详见 `.claude/agents/compliance-redline.md`。
