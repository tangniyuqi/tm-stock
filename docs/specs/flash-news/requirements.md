# 快讯列表与全文搜索 · 需求规格

- **等级**：B（新业务流程 + 外部数据源）
- **关联目标**：GOALS.md G1（验证阶段的免费引流入口）
- **状态**：草案，待评审（2026-07-30 按 `compliance-redline.md` v2 复核修订）
- **合规定性**：客观信息聚合。风险不在"有没有出现公司名"，而在
  **我方有没有对内容做加工与定性** —— 详见 §3.4 转载口径

## 1. 业务背景

快讯是一期**免费引流**入口：用户不付费也能用，用它换取打开频次与留存，
再向付费的「题材查询」转化。它本身不产生收入，但决定日活。

## 2. 用户与场景

- **谁**：波段 / 上班族散户（一期主要人群）
- **什么情况**：盘中或收盘后想快速扫一眼"今天发生了什么"；或想查某个关键词的历史消息
- **想达成**：30 秒内扫完当日重要信息；能搜到过往某条消息

## 3. 功能需求

### 3.1 快讯列表（pages/news）

- 倒序展示快讯流，字段：**时间 · 正文 · 来源**（+ 可选题材标签）
- **自动刷新**：30–60 秒一次；新内容插入顶部并提示"N 条新消息"
- 下拉刷新、上拉分页（每页 20 条）
- 点击条目：有原文链接则跳原文，无则展开全文
- 列表项文本超长折叠，可展开

### 3.2 全文搜索

- 搜索框入口在列表顶部
- 关键词搜索历史快讯，命中词高亮
- 结果按**相关度 / 时间**可切换排序
- 输入防抖 300ms；空结果显示引导文案

### 3.3 数据来源与刷新策略

- 快讯来自**第三方源**，后端统一接入并落库，前端只调本平台接口
- 后端按固定周期拉取增量，去重后入库
- 全文检索一期可先用 MySQL，数据量上来后切 Meilisearch（**接口契约不变**）

### 3.4 🔴 转载口径（本需求的合规重点）

> 快讯的风险**不是"正文里出现了公司名"**——真实新闻本来就天天写公司名，
> 要求"不出现个股名称"既做不到，也没有法律依据。
> **风险在于我方对内容做了什么加工。**

| ✅ 允许 | ❌ 禁止 |
|--------|--------|
| 原文转载（**不改标题、不改正文**） | 删改、断章取义式截取 |
| 必标**来源**与**原文链接** | 隐去来源、伪装成自有内容 |
| 打**题材标签**（编辑性归类） | 挂**个股清单**（"这条消息相关个股：A/B/C"） |
| 呈现发布时间 | 加"利好 / 利空 / 重大 / 值得关注"等我方定性 |
| — | 附个股涨跌幅（快讯页不出现行情） |
| — | **我方自行创作**带预测/评价的标题 |

**"我方不得自行创作"这条同样约束开发期的 mock 数据**——
mock 文案极易被直接沿用到正式版（本项目已实际发生过：
`pages/index/index.uvue` 里的示例标题含"将迎来黄金期"）。

**为什么不挂个股清单**：那是最典型的"催化剂选股"形态。
需要这层关联的用户，可以点**题材标签**进题材详情页看成分股——
中间隔了一跳客观分类，且那一跳有依据可查（见 `theme-query`）。

> 题材标签属**编辑性归类**（对信息分类），与 `theme-query` 里的
> 题材↔个股映射（指向可交易证券）风险等级不同，因此不要求原文摘录级依据；
> 但仍须可解释、不得为蹭流量硬贴。

## 4. 验收标准（可测）

- [ ] **AC1**：列表默认加载 20 条，按发布时间倒序，字段含时间/正文/来源
- [ ] **AC2**：页面停留 60 秒内至少触发 1 次自动刷新；有新数据时顶部出现"N 条新消息"提示
- [ ] **AC3**：下拉刷新返回最新数据；上拉加载下一页且**不重复、不跳条**
- [ ] **AC4**：搜索"任意常见词"能返回结果，命中词高亮；结果可按时间/相关度切换
- [ ] **AC5**：搜索无结果时显示空态文案"没有找到相关快讯，换个词试试"
- [ ] **AC6**：列表接口 p95 响应 < 800ms（100 条以内数据集）
- [ ] **AC7**：每条快讯**显示来源**；有原文链接的可跳转
- [ ] **边界**：空数据（首次无快讯）显示空态；单条正文 >500 字正确折叠；分页到底显示"没有更多了"
- [ ] **异常**：接口失败显示错误态 + 重试按钮，**不白屏**；断网后恢复能自动重连
- [ ] **性能**：连续自动刷新 10 分钟不出现内存持续增长或卡顿

### 🔴 合规验收（v2 修订）

> 原 AC「列表与搜索结果中不出现个股名称/代码/涨跌幅」**已废除**——
> 真实新闻正文必然出现公司名，该条既做不到也无法律依据。改为下列五条：

- [ ] **🔴 AC8**：每条快讯**必有来源**；有原文链接的可跳转；来源不得隐去
- [ ] **🔴 AC9**：**我方不添加**任何定性标签（利好/利空/重大/值得关注）——
      接口与页面均无此类字段
- [ ] **🔴 AC10**：快讯条目**不挂个股清单、不附个股涨跌幅**
      （接口 `FlashItem` 无 `stocks` / `changePct` 类字段）
- [ ] **🔴 AC11**：**我方自建/示例**快讯文案通过 `check-compliance-words.sh`；
      **mock 数据同样受检**
- [ ] **🔴 AC12**：转载正文与源站一致（抽样比对 ≥5 条），未被删改

## 5. 不做什么（Out of Scope）

- ❌ 个性化关键词推送（二期候选）
- ❌ 快讯的评论、点赞、分享
- ❌ **快讯条目直接挂个股清单 / 附个股涨跌幅**（催化剂选股形态，**红线**）
  —— 需要这层关联的用户走「题材标签 → 题材详情页」，见 §3.4
- ❌ 快讯情绪 / 利好利空 / 重要性标注（我方定性，**红线**）
- ❌ 付费墙（快讯一期全免费）

## 5.1 与 `theme-daily`（题材动态）的区别

两者页面长得像，容易做重复或做串，先划清：

| | `flash-news` 7×24 快讯 | `theme-daily` 题材动态 |
|---|---|---|
| 是什么 | **全量资讯流** | **按题材归类的当日动态** |
| 组织方式 | 按时间倒序，实时滚动 | 按**交易日**分组，可回看历史 |
| 主体 | 一条条消息 | 一个个**题材**（消息是它的注解） |
| 带涨跌幅 | ❌ 不带 | ✅ 带**题材层**涨跌幅（快照） |
| 入口 | 底部 Tab「7x24快讯」 | 首页第一个 Tab |
| 作用 | 提高打开频次 | 把用户导向付费的题材详情 |

## 6. 前置风险（阻塞项）

> 🔴 **第三方快讯源的商用授权未落实**——这是**上线前置阻塞**，不是技术问题。
> 未取得授权前：只做技术链路打通与自采公开源（政策原文、交易所公告），
> **不得整段转载第三方内容**；只抽事实要素 + 标来源 + 跳原文。
> 详见 `.claude/agents/compliance-redline.md`。
