**OWASP LLM Top 10（2025，调研读取官方页）**：LLM01 提示注入（间接注入来自外部网页与文件，RAG 不能完全缓解）；LLM05 不当输出处理（模型输出按不可信输入对待，前端转义）；LLM06 过度代理（最小功能与权限、避免开放式工具）；LLM09 误导信息（自动校验加人工监督加界面标注）；LLM10 无界消耗（钱包拒绝服务，要输入阈值、配额、超时、降级）。

**流水线各步的借鉴来源**（design.md 第 3.2 节）：入口封闭 ← NeMo 输入 rail 与固定拒答；来源固化 ← DeerFlow 快照；抽取隔离 ← CaMeL 的隔离模型与 Map-Reduce、ragas 的断言拆分；**逐字校验 ← 自研**（open_deep_research 恰缺这一环，RAGFlow 的 Go 句切分可参考）；**共现校验 ← 自研**（针对 STORM 论文所述的"推断链接"）；蕴含裁判 ← NeMo、ProvenanceLLM、ragas、OpenAI 示例的核验员；红线检测 ← DeepEval 的"先抽取再判"加我们自己的词表；抽样复核 ← 复用"贡献审核"后台。

**裁判的天花板**（调研读取，ALCE 论文）：人机一致性 κ 为 0.698（召回）与 0.525（精确），"部分支持"最难判。这是 D3 选 A、且裁判必须 fail-closed 的原因。

| Formance、Blnk | MIT（PG）；Apache-2.0 | 已提交不可改，更正用冲正新事务；交易状态变化新建记录并以父交易关联 | 追加式与冲正 | 多一套基础设施 |

**结论**：不嵌入任何一个；用 MySQL 自建"批次 + 冻结单 + 只增流水"，借语义不借代码（design.md 第 4 节）。

### 5.3 吸收与不做

- **做**：会员含一次性赠送、另可加购积分包；批次的优先级、到期、购买与赠送区分（也是分成口径的数据基础）；支付门控入账；hold → capture/void；冲正只增不改；价格快照；贡献内容的商用授权条款（法务）。
- **不做**：信任旁路；允许负余额；非幂等退款；Redis 先行扣减；浮点金额；单列余额无流水；月度清零式积分；"捐款换积分"与承诺收入分成；AI 荐股或研究类功能；直接嵌入 AGPL 代码；首版引入 TigerBeetle、Formance、Blnk 作内核。

## 8. 须持牌律师确认的问题清单

1. "题材 → 环节 → 成分股（附依据）+ 涨跌幅"是否落入〔2012〕40 号第一条的排除条款？依据由编辑或 AI 归纳（关联度、热度、逻辑摘要）是否构成"其他分析、预测或建议"？
2. 纯事实层收取会员、积分或广告分佣，是否仍触发第二条的"间接获取经济利益"（其前提是否必须为"荐股软件"）？
3. L1、L2 是否属"向境内公众提供生成式 AI 服务"，是否具"舆论属性或社会动员能力"；走"登记"的主体、材料、周期；调用已备案模型 API 与自建、微调的归类；**备案或登记之前的内测、灰度是否算"向公众提供"**；L0 内部助手是否适用暂行办法第二条第三款。
4. 我方是否可能构成"第三方互联网平台"（须金融机构依法委托）；未受委托展示开户链接是否属"变相营销"；按开户、交易、佣金分成是否合法；"投教、课程"付费如何界定；AI 回答券商、理财问题是否属第二十条"互动咨询"；产品、栏目、按钮命名是否触碰第十八条。
5. 用户贡献分成：向贡献者付费的性质，对用户个股观点的责任（"抢帽子"类案件），支付、提现、个税、反洗钱；充值型积分的法律性质与消费者权益（预付、退款、有效期、未成年人）。
6. 跨境银行卡开户推广：境外银行未经许可面向境内居民营销是否属第六条"非法金融活动"；"信息介绍或广告"形式是否可行；分佣是否算"提供便利"；与外汇额度、反洗钱的关系；2026-05 整治方案文字限于证券期货基金，是否延伸至银行与支付。

9. 刑事边界：无证荐股、导流的非法经营风险。
10. 来源语料授权：公告原文、政策文件、快讯的再使用；**快照留存**是否构成复制或汇编；行情数据展示。
