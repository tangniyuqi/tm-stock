# 题材查询 · 需求规格

- **等级**：B（新业务流程，且是一期核心付费点）
- **关联目标**：GOALS.md G1（验证"有没有人为此付费"的承载功能）
- **状态**：v2 草案，待评审
- **版本**：v2（2026-07-30）—— 按 [ADR-0003](../../adr/0003-个股客观事实层可做.md) 重写，
  v1 的"一期不含个股"口径已废弃
- **合规定性**：🔴 **高关注**——本需求最接近红线，全程受 `compliance-redline.md` v2 约束

## 1. 业务背景

「题材查询」是一期**唯一付费点**：让用户看懂"某个题材是什么、涉及产业链哪些环节、
**这些环节下有哪些公司、依据是什么**"。

v1 曾把漏斗止于"产业链环节层"，砍掉了个股——那会掏空产品价值（ADR-0002 自己也承认
"接近大厂免费层已有的东西"）。v2 恢复个股，但**严格限定在客观事实层**。

## 2. 用户与场景

- **谁**：波段 / 上班族散户
- **什么情况**：看到某个题材词（如"低空经济"）不懂是什么、不知道涉及哪些公司
- **想达成**：3 分钟看懂一个题材的构成，并且**知道每家公司为什么被归到这里**

## 3. 🔴 合规边界（本需求的第一约束）

> **分界线是「事实 vs 我方观点」，不是「有没有出现个股」。**

| ✅ 做 | ❌ 不做（红线） |
|------|---------------|
| 题材是什么（客观定义） | "谁受益 / 谁是龙头 / 纯正度" |
| 因何政策/事件被关注（客观转述 + 原文链接） | 涨跌预测 / 择时 / 目标价 / 投资评级 |
| 产业链**环节**划分与说明 | 按"相关度 / 受益程度"排序打分 |
| **环节下挂成分股**（名称 + 涨跌幅） | **个股详情页**（基本面 / 财务 / K线 / 技术指标） |
| **每条归属的依据**（来源 + 原文摘录 + 链接 + 时点） | 无依据的映射入库 |
| 按客观字段排序（涨跌幅 / 代码 / 市值） | 无客观依据的高亮 / 置顶 / 首推某只 |
| 题材层、环节层涨跌统计（标口径） | 个性化"为你推荐个股" |

### 🧭 本需求的合规命门

**每条「题材 ↔ 个股」映射必须带证据，且用户可查。**
若归属依据来自我方主观判断，就退化成"品种选择"（落入要件二）。
→ 因此设计上把**"依据"做成用户可点开的一等公民**，而不是藏在后台。

## 4. 功能需求

### 4.1 题材库（分类浏览）
- 一级 → 二级 → 三级分类逐级下钻（左侧一级、右侧二/三级）
- 分类名沿用市场通用叫法；**不加评价性标签**
- 点击三级题材 → 题材详情页

### 4.2 题材搜索
- 按题材名搜索，支持拼音首字母
- 结果显示题材名 + 所属分类路径

### 4.3 题材详情页（核心付费页）

对应设计稿第三张图。结构：

| 层 | 内容 | 权限 |
|---|------|------|
| **顶层** | 题材名 + 分类路径 + 一句话通俗解读 + 更新时间 + 数据来源 | 免费可见 |
| **中层** | **产业链环节折叠列表**：环节名 + 环节涨跌幅（可展开） | **付费** |
| **环节内** | 该环节下**成分股卡片**：股票名 + **涨跌幅（延时15分钟）** + 依据入口 | **付费** |
| **底层** | 关联事件时间线（客观标题 + 原文跳转） | **付费** |

**关键交互：点击个股 → 弹出「归属依据」浮层**（不跳转、不进详情页）
浮层内容：来源类型（公告/年报/招股书/官方目录）、**原文摘录**、原文链接、采集时点。

> 这是本需求最重要的设计决定：它同时满足①合规要求依据可溯源可展示、
> ②用户真正想知道"凭什么说这家公司属于这个题材"、③避开个股详情页红线。

### 4.4 行情展示规则（强制）
- 口径：**延时 15 分钟**（ADR-0004 相关决策）
- 页面**必须明示**"行情延时 15 分钟"，并展示**数据时点**（不是"刷新时间"）
- 环节 / 题材层涨跌幅为**派生统计**，必须可展开看到聚合口径（如"成分股等权平均"）
- 数据源授权未落地前，只能用**明确标注**的模拟数据（"示例数据，非真实行情"）

### 4.5 排序与高亮规则（合规敏感）
- 成分股默认按**涨跌幅降序**，UI **明示当前排序依据**，用户可切换（代码 / 涨跌幅）
- **禁止**按"相关度 / 纯正度 / 受益度"排序
- **高亮只能是「用户选中态」**——点击某只个股查看依据时高亮它；
  **禁止**默认高亮 / 置顶 / 首推任何一只

## 5. 验收标准（可测）

- [ ] **AC1**：分类页展示一级分类；点击后右侧显示其二/三级题材，层级正确
- [ ] **AC2**：点击三级题材进入详情页，顶层四要素齐全（名称/路径/解读/更新时间+来源）
- [ ] **AC3**：已订阅用户可见产业链环节列表；环节可展开/收起，展开后显示成分股
- [ ] **AC4**：每只成分股显示**名称 + 涨跌幅**；涨红跌绿；无行情时显示"—"而非 0
- [ ] **AC5**：点击成分股弹出依据浮层，含**来源类型 + 原文摘录 + 原文链接 + 采集时点**四项
- [ ] **AC6**：页面明示"行情延时 15 分钟"及**数据时点**
- [ ] **AC7**：环节/题材涨跌幅可展开查看**聚合口径说明**
- [ ] **AC8**：未订阅用户中层及以下被遮罩，显示订阅入口与**剩余试吃次数**
- [ ] **AC9**：试吃额度用尽后显示"今日试吃已用完"，次日 GMT+8 00:00 重置
- [ ] **AC10**：题材搜索可用，支持中文与拼音首字母
- [ ] **AC11**：详情页接口 p95 < 1s
- [ ] **🔴 AC12（合规）**：详情页**无任何**价值评价词、排名标签、预测择时表述；
      通过 `check-compliance-words.sh`
- [ ] **🔴 AC13（合规）**：**不存在**个股详情页路由与接口（基本面/K线/技术指标）
- [ ] **🔴 AC14（合规）**：**无依据的映射不得出现在接口返回中**——
      构造一条缺 `source_excerpt` 的映射，接口须过滤掉它（不是显示空依据）
- [ ] **🔴 AC15（合规）**：默认不高亮任何个股；高亮仅在用户点击后出现
- [ ] **🔴 AC16（数据真实）**：行情为模拟数据时页面**显著标注**"示例数据，非真实行情"
- [ ] **边界**：题材无环节数据 → "暂无产业链数据"；环节无成分股 → "暂无已收录公司"
- [ ] **异常**：接口失败可重试；未登录访问付费内容引导登录
- [ ] **权限**：游客可浏览分类与题材列表；中层及以下需登录 + 订阅或试吃

## 6. 不做什么（Out of Scope）

- ❌ **个股详情页**（基本面、财务、K 线、技术指标）—— 红线，非排期问题
- ❌ 个股搜索、自选股、个股关注
- ❌ 题材轮动表（**独立需求**，见首页第二个 tab，另行立项）
- ❌ 题材动态按日浏览（**独立需求**，见 `docs/specs/theme-daily/`）
- ❌ 题材关注 / 收藏
- ❌ AI 深度解读（一期只做名词定义 + 公开事实复述，须加护栏 + 标注 AI 生成）
