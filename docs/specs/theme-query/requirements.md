## 1. 业务背景

「题材查询」是一期**唯一付费点**：让用户看懂"某个题材是什么、因何而起、涉及产业链哪些环节"。
它决定这门生意是否成立——若用户不愿为它付费，一期商业模式即被证伪（见 GOALS G1）。

## 2. 用户与场景

- **谁**：波段 / 上班族散户
- **什么情况**：看到某个题材词（如"低空经济"）不懂是什么；或想系统了解某行业构成
- **想达成**：3 分钟看懂一个题材的来龙去脉与产业链构成

## 3. 🔴 合规边界（本需求的第一约束）

| ✅ 做 | ❌ 不做（红线） |
|------|---------------|
| 题材是什么（客观定义） | 个股清单 / 成分股 / 个股涨跌幅 |
| 因何政策/事件被关注（客观转述 + 原文链接） | "谁受益 / 谁是龙头" |
| 产业链有哪些**环节**、各环节做什么 | 环节下挂具体公司 |
| 题材层**历史**涨跌统计（标来源、标时点） | 涨跌预测 / 轮动择时 / 排名趋势 |
| 分类目录浏览 | "优选 / 推荐 / 潜力"类标签 |

**漏斗终点必须止于「产业链环节」层**，不得下钻到可交易证券。

## 4. 功能需求

### 4.1 题材库（分类浏览，pages/segment）
- 一级 → 二级 → 三级分类逐级下钻（左侧一级、右侧二/三级，购物式）
- 分类名沿用市场通用叫法；**不加评价性标签**
- 点击三级题材 → 题材详情页

### 4.2 题材搜索
- 按题材名搜索，支持拼音首字母
- 结果显示题材名 + 所属分类路径

### 4.3 题材详情页（核心付费页，三层结构）

| 层 | 内容 | 权限 |
|---|------|------|
| **顶层** | 题材名 + 分类路径 + 一句话通俗解读 + 更新时间 + 数据来源 | 免费可见 |
| **中层** | 产业链环节图（题材 → 各环节 + 环节说明）+ 关联事件时间线 | **付费** |
| **底层** | 题材层历史涨跌统计（客观、标来源、不做趋势判断） | **付费** |

- 未订阅：顶层可见，中/底层遮罩 + 订阅入口 + 每日 N 条试吃额度
- 全页固定免责："本平台为公开信息聚合与历史数据统计，不构成任何投资建议。"

## 5. 验收标准（可测）

- [ ] **AC1**：分类页展示一级分类列表；点击后右侧显示其二/三级题材，层级正确
- [ ] **AC2**：点击三级题材进入详情页，顶层四要素齐全（名称/路径/解读/更新时间+来源）
- [ ] **AC3**：已订阅用户可见中层产业链环节图与底层历史数据
- [ ] **AC4**：未订阅用户中/底层被遮罩，显示订阅入口与**剩余试吃次数**
- [ ] **AC5**：试吃额度用尽后再访问显示"今日试吃已用完"，次日 GMT+8 00:00 重置
- [ ] **AC6**：题材搜索可用，支持中文与拼音首字母
- [ ] **AC7**：详情页接口 p95 < 1s
- [ ] **🔴 AC8（合规）**：详情页**不出现任何个股名称、股票代码、个股涨跌幅**
- [ ] **🔴 AC9（合规）**：全页文案通过禁用词扫描（`check-compliance-words.sh`）
- [ ] **🔴 AC10（数据真实）**：历史涨跌数据标注**来源与统计口径**；数据缺失显示"暂无数据"而非 0 或占位值
- [ ] **边界**：题材无产业链数据时环节区显示"暂无产业链数据"；无关联事件时时间线显示空态
- [ ] **异常**：接口失败显示错误态可重试；未登录访问付费内容引导登录
- [ ] **权限**：游客可浏览分类与题材列表；详情中/底层需登录 + 订阅或试吃

## 6. 不做什么（Out of Scope）

- ❌ **个股 / 成分股 / 个股涨跌幅**（ADR-0002，二期持牌后再议）
- ❌ 题材轮动 90 天表（后续迭代，且需从上线起积累快照）
- ❌ 题材关注 / 收藏（可后续加）
- ❌ AI 深度解读（一期只做名词定义 + 公开事实复述，且须加护栏 + 标注 AI 生成）
- ❌ 历史日期切换
