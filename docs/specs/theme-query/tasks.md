## 前置阻塞（开工前必须解决）

1. ⛔ **成分股映射的依据采集**（任务 4）是**本需求最大的人力投入**，
   也是合规命门与护城河。**不能靠自动生成糊弄**——依据必须是可核对的原文摘录。
2. ⛔ **行情数据商用授权**（`docs/上线前置授权清单.md` §2）未落实 →
   `quote.enabled=false`，涨跌幅整体不上线；**不用假数据凑**。
3. ⛔ **律师书面复核**（GOALS G3）→ 重点是"依据可溯源机制是否足以排除品种选择认定"，
   以及默认按涨跌幅排序这个灰区。中层与依据浮层须做成**可整体下线的开关**。
