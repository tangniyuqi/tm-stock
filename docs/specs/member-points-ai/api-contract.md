# 会员、积分与内容授权接口契约

状态：设计契约，未实现。所有金额、积分数量和奖励比例均由服务端配置；本文件不包含正式价格。

## 统一约定

- 路径前缀：`/api/v1`
- 统一响应：`{ "code": 0, "msg": "", "data": {} }`
- 所有写接口必须携带登录态；服务端从登录态取得 user_id，不接受客户端传入的 user_id。
- 所有写接口携带 `Idempotency-Key`；同一用户、同一业务键重复请求返回第一次结果。
- 积分以整数记账，余额不能为负；充值、赠送、冻结、结算、释放、奖励和冲正均写入不可变流水。
- 权限校验在服务端完成；客户端的隐藏、置灰和按钮状态只用于展示，不是安全边界。

## 会员与开通

### `GET /member/entitlement`

返回当前会员状态、可查看内容范围、到期时间和开通赠送说明。未登录返回登录所需错误码，不返回其他用户信息。

### `POST /member/orders`

请求：`{ "plan_id": "string", "return_url": "string" }`

返回：订单号、应付金额、支付状态、开通后赠送积分数量。服务端只接受后台已启用的 plan_id；return_url 仅允许站内白名单。

### `POST /member/orders/{order_id}/callbacks`

支付渠道回调入口。以渠道签名和服务端订单状态为准，成功状态转换只能执行一次；成功后在同一事务中开通会员并写入一次赠送积分流水。客户端不能调用此接口代替支付回调。

## 内容授权

### `GET /content/{content_type}/{content_id}/preview`

返回基础公开内容、可解锁内容摘要、来源信息、当前用户是否已购买和本次价格。基础归属依据不因收费被遮挡；详细整理内容只返回摘要。

### `POST /content/{content_type}/{content_id}/unlock`

请求：`{ "expected_price_points": 0 }`

服务端重新读取当前价格和用户余额，校验会员/内容状态、有效期和既有授权；价格与客户端预期不一致时拒绝并要求刷新。成功时原子完成扣减和授权写入，重复购买返回既有授权且不重复扣分。

### `GET /content/{content_type}/{content_id}`

只有基础公开内容或有效授权可读取完整内容；响应包含内容版本、来源字段和可公开的审核状态。下线、过期或撤回内容不得通过缓存继续读取。

## 积分账户

### `GET /points/account`

返回可用、冻结、赠送和贡献奖励余额，以及有效期最早的积分批次摘要。不返回支付渠道敏感信息。

### `GET /points/ledger?page=1&page_size=20`

返回分页流水：类型、变动值、余额快照、业务单号、备注、创建时间和状态。流水只读，分页排序按服务端固定规则。

### `POST /points/recharges`

请求：`{ "package_id": "string", "return_url": "string" }`

创建充值订单，到账积分和金额以后台套餐配置为准。套餐不可用、地区不适用或 return_url 不在白名单时拒绝。

### `POST /points/recharges/{order_id}/callbacks`

支付回调。校验签名、金额、币种和订单状态；重复回调返回已处理结果，不重复到账。退款必须生成关联冲正流水，不能直接修改原流水。

## 贡献与奖励

### `POST /contributions`

请求：`{ "content_type": "theme_logic", "content_id": 0, "title": "string", "body": "string", "evidence": [{ "source_type": "string", "source_excerpt": "string", "source_url": "string", "collected_at": 0 }] }`

服务端保存待审核版本和来源证据。提交不立即奖励、不立即对外出售；同一用户对同一内容的重复版本进入幂等或合并流程。

### `GET /contributions/mine`

返回本人投稿的审核状态、退回原因、可修改时间和已结算奖励；不展示内部审核备注或其他用户资料。

### `POST /admin/contributions/{id}/review`

运营后台专用。请求包含审核结果、可发布版本和奖励配置快照。通过时发布内容并记录奖励待结算事件；驳回时记录原因，不产生奖励。

### `POST /content/{content_type}/{content_id}/share-events`

记录可公开摘要分享事件，不把按钮点击直接当作有效贡献。有效行为由服务端按设备、账号、时间窗口和访问结果判定；反作弊撤销必须关联原奖励流水。

## AI 任务

### `POST /ai/tasks/quote`

请求：`{ "analysis_type": "light|deep", "subject_type": "theme|topic", "subject_id": 0 }`

返回任务预计积分、当前余额、资料范围和价格版本。此接口只报价，不扣积分。

### `POST /ai/tasks`

请求：`{ "analysis_type": "light|deep", "subject_type": "theme|topic", "subject_id": 0, "price_version": "string" }`

服务端校验价格版本和余额后冻结积分，创建幂等任务。轻度任务只做来源明确的事实整理；深度任务分阶段采集、核验、汇总。禁止输出个股价值判断、价格方向判断或买卖操作。

### `GET /ai/tasks/{task_id}`

返回阶段、进度、状态和可公开结果摘要。失败、取消、超时释放冻结积分；成功交付后结算。重复查询不产生额外费用。

### `GET /ai/tasks/{task_id}/events`

SSE 只推送阶段状态、错误码和公开结果可用通知，不推送内部提示词、原始密钥、完整内部推理或其他用户资料。

## 错误码

| code | 含义 |
|---:|---|
| 40101 | 未登录 |
| 40301 | 无权查看 |
| 40901 | 价格版本已变化 |
| 40902 | 已存在有效授权 |
| 40903 | 请求幂等键已使用 |
| 42201 | 积分余额不足 |
| 42202 | 套餐或内容不可用 |
| 42901 | 操作频率受限 |
| 50201 | 外部支付或模型服务暂不可用 |

## 事务与恢复验收

- 支付回调、会员开通和初始积分赠送必须在可恢复事务中完成；崩溃重试不能重复开通或赠送。
- 内容解锁扣分与授权写入必须同事务；扣分成功而授权失败时自动回滚或进入可审计补偿队列。
- AI 任务冻结与任务创建必须关联；进程重启后可恢复，阶段重试不能产生第二笔冻结。
- 贡献分成只能来自实际完成的内容消费；退款或反作弊时按关联流水冲正。
- 所有跨用户读取按 user_id 和授权对象过滤；缓存键必须包含用户授权维度或只缓存公开内容。
