# 题材宝典前端页面范围与开发清单

> **文档性质**：前端范围基线（持续维护），不是一次性开发总结。
>
> **更新时间**：2026-08-31
>
> **适用端**：uni-app x H5 C 端；运营后台另列为独立工作流。
>
> **状态口径**：
> - ✅ 已有页面结构：代码已存在，并完成过 H5 渲染核验；不代表真实接口或生产能力已完成。
> - 🟡 部分完成：有占位或部分交互，仍需按本清单补齐。
> - 🟡 受控关闭态：页面结构已落地，但因后端、授权或法律前置条件未满足，输入/提交能力必须保持关闭。
> - ⬜ 待开发：页面或关键能力尚未实现。
> - ⛔ 本期不做：有明确的产品、合规或授权边界，不进入当前开发排期。

### 1.1 当前已存在但不能算“完成”的页面

`pages/news/*`、`pages/ai/index`、`pages/member/*` 当前主要是合规占位态。它们能渲染并不等于业务页面已经交付；在真实内容授权、会员后端和正式法律文本到位前，保持空态/关闭态是正确行为。

### 1.2 高保真原型覆盖情况

当前核心画板 [`overview.png`](../../prototypes/theme-data-remediation/overview.png) 覆盖：首页·题材动态、题材详情、归属依据浮层 3 个核心画面；[P0 页面原型](../../prototypes/theme-data-remediation/p0.html) 覆盖题材库、会员与账号主流程；新增的 [P0 状态板](../../prototypes/theme-data-remediation/p0-states.html) 将 P0 必须回归的状态拆成 53 个独立手机画面或明确弹层，覆盖：

- 题材库输入/提交中/加载/无结果/接口错误/长名称；
- 题材详情未登录、试吃可用、订阅有效、试吃用尽、无环节、无公司、环节收起与映射过滤；
- 归属依据加载、成功长摘录、接口失败、四项证据缺失、非 HTTPS 链接、关闭，以及外部原文确认/拦截和浏览器返回；
- 日历日期选择（已选、未来日期和数据起始日前置灰）；
- 会员中心加载、网络失败、未开通、有效、过期、试吃用尽、退出/注销确认与完成；
- 登录手机号/验证码校验、过期、频控、发送中、失败与成功回跳；
- 兑换码空值、格式错误、提交中、成功、码不存在、已使用、已过期、账号不匹配和临时锁定；
- 全局断网、超时、维护、无数据/小屏与字体放大。

## 2. 需要补齐的页面级交互与状态

这些内容不一定新增路由，但必须有原型、实现和回归用例。

| 模块 | 必须设计的状态/交互 | 交付判断 |
|---|---|---|
| 日期选择 | 日历月切换、本月、已选日期、未来日期置灰、数据起始日前置灰、取消/确认 | 选中日期与接口请求日期一致；未来日期不可提交 |
| 题材库搜索 | 输入中、清除、提交中、无结果、接口错误、结果过长、省略与可访问名称 | 不返回未经审核题材；错误可重试 |
| 题材详情权限 | 未登录、试吃可用、订阅有效、试吃用尽；锁定内容不可通过前端绕过 | 权限由服务端字段驱动，前端只负责表现 |
| 产业链折叠 | 首个环节默认展开、其他环节展开/收起、无公司、映射被过滤 | 不以评价字段决定顺序或高亮 |
| 归属依据 | 加载中、成功、接口失败、四项证据缺失、长摘录滚动、无效/非 HTTPS 链接、关闭 | 不具备四项证据的记录不可展示 |
| 外部原文 | 点击确认、取消、域名/协议校验失败、浏览器返回 | 页面不得直接拼接不受控 URL |
| 登录 | 手机号格式错误、验证码为空/过期/频繁、协议未勾选、登录失败、成功回跳 | 默认不勾选协议；不收集明文以外的额外信息 |
| 会员中心 | 访客、有效、过期、试吃耗尽、网络失败、退出确认、注销确认/完成 | 只显示服务端脱敏手机号 |
| 兑换码 | 空值、格式错误、提交中、成功、四类业务失败、临时锁定 | 不出现支付、收款或二维码入口 |
| 资讯 | 首次加载、轮询刷新、有新消息、空态、无授权关闭、搜索历史、搜索无结果、分页到底 | 来源、时间、原文入口始终可查 |
| 资料整理 | 来源筛选、搜索、空态、审核中不可见、链接失效 | 不出现 AI 结论、个股分析或行情数值 |
| 全局 | 网络断开、接口超时、服务维护、页面无数据、字体放大、小屏横向溢出 | 所有错误态有明确重试或返回路径 |

## 6. 推荐开发顺序

1. **P0 原型基线已落地**：主流程见 [P0 页面原型](../../prototypes/theme-data-remediation/p0.html)，独立异常与权限状态见 [P0 状态板](../../prototypes/theme-data-remediation/p0-states.html)；正式文本、错误码和服务端权限接入后按同一画面回归。
2. **P0 契约联调**：题材搜索/详情/依据、会员登录/试吃/兑换码；所有页面只访问同源 `/api/v1/*`。
3. **P0 回归交付**：H5 编译、375px 交互、无障碍、合规词与外链安全检查。
4. **P1 内容栏目**：题材动态、资讯列表/详情；先完成授权和数据契约，再开放真实内容。`资料整理`按 ADR-0005 暂不开发。
5. **后台工作流**：题材维护、依据录入、审核、动态录入、兑换码和审计；按 `admin-console` 规格独立排期。
6. **授权后能力**：行情展示及其延时/数据时点状态单独评审，不与页面收口混合上线。

## 7. 页面完成定义

一个页面只有同时满足以下条件，才可标记为“完成”：

- 有对应高保真原型，且正常态、加载态、空态、错误态、权限态均有说明；
- 已在 `pages.json` 注册（组件除外），路由可从真实入口到达；
- 使用内部接口契约，浏览器网络请求不出现上游量化地址；
- 真实数据缺失时显示空态/置灰，不使用演示值冒充生产数据；
- 关键交互有 H5 回归证据，按钮触达面积和键盘/读屏顺序通过检查；
- 通过合规禁用词、密钥、架构和 `git diff --check` 门禁；
- 依赖的授权、会员、审核和法律前置条件已明确，未满足时页面保持受控关闭态。
