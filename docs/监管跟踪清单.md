- 有变更时：在 `docs/adr/` 追加更新说明；改 `compliance-redline.md` 与 `.cursor/rules/tm-stock-compliance.mdc`（两处同步）；
  词表与句式规则**只增不减**（`scripts/compliance-forbidden-words.txt`，再运行 `bash scripts/sync-guard-words.sh`）。
