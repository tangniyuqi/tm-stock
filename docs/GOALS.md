# 季度目标（需求过滤器）

> **当季目标 ≤ 3 条**。挂不上这里的需求，先问"是否该现在做"。

## 当前阶段：一期 · 验证优先

### G1. 验证「安全版」是否有人付费（最高优先级）

- **为什么**：合规裁定后，一期只能做题材/行业客观信息（不含个股），
  这部分接近大厂免费层已有的内容 —— **愿不愿为它付费尚未被证明**。
- **怎么做**：不写代码。内容（小红书）+ 私域（知识星球 ¥29/月 concierge）实测。
- **成功指标**：8 周内 ~1000 真实关注 · ≥30–50 人真金付费 · **次月续费 ≥50%**（订阅生死线）
- **决策门**：达标 → 才进入开发；有人看不付费 → 改变现模式；关注都起不来 → 止损

### G2. 打好工程与合规地基

- **为什么**：地基不稳会在后期反复返工；合规错误是公司级风险。
- **成功指标**：四层护栏可用（合规词/密钥/Go 门禁）· 规范齐备 · 合规红线机器可检
- **状态**：本次已完成主体

### G3. 合规边界取得专业背书

- **为什么**："题材层 ≠ 具体证券"这一根本假设**尚未经持牌律师验证**，是全案最大单点风险。
- **怎么做**：以 `.claude/agents/compliance-redline.md` 为底稿，请证券合规律师出具书面意见。
- **成功指标**：拿到书面法律意见，据此确认或修订一期功能边界
