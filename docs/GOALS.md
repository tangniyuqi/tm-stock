# 季度目标（需求过滤器）

> **当季目标 ≤ 3 条**。挂不上这里的需求，先问"是否该现在做"。

## 当前阶段：一期 · 验证优先

### G1. 验证「可审计的题材库」是否有人付费（最高优先级）

> **v2（2026-07-30 修订）**：原表述建立在旧红线"一期不含个股"之上，
> [ADR-0003](adr/0003-个股客观事实层可做.md) 推翻该口径后，**待验证的假设也随之改变**。

- **待验证的命题**：
  用户愿不愿为「**归属依据可查**」付钱——即知道
  "茂莱光学被归入光源环节，是因为 2025 年报披露该业务收入占比 34.2%"
  这件事，值不值 ¥29/月。
- **为什么仍需验证**：
  免费产品（同花顺/东财等）已经给了"概念板块 → 成分股 → 涨跌幅"。
  我们独有的只有**依据可溯源 + 产业链环节结构化**——
  **它值不值钱，尚未被证明。**
- **怎么做**：**不写代码**。内容（小红书）+ 私域（知识星球 ¥29/月 concierge 人工交付）。
  人工交付的就是"题材 + 环节 + 成分股 + 依据原文"，与产品化后的价值主张一致。
- **成功指标**：8 周内 ~1000 真实关注 · ≥30–50 人真金付费 · **次月续费 ≥50%**（订阅生死线）
- **决策门**：达标 → 进入 [ADR-0006](adr/0006-G1最小验证路径.md) 的阶段 1 最小产品；
  有人看不付费 → 改变现模式；关注都起不来 → 止损

### G2. 打好工程与合规地基

- **为什么**：地基不稳会在后期反复返工；合规错误是公司级风险。
- **成功指标**：四层护栏可用（合规词/密钥/架构/CI）· 规范齐备 · 合规红线机器可检
- **状态**：主体已完成

### G3. 合规边界取得专业背书

- **为什么**：**全案最大单点风险**。
  ADR-0003 的「事实 vs 观点」分界与「依据可溯源」机制是**工程侧自评结论**，
  尚未经持牌律师验证。
- **怎么做**：以 `.claude/agents/compliance-redline.md` v2 为底稿请证券合规律师出具书面意见。
- **重点复核项**：见 `docs/上线前置授权清单.md` §7（六项）
- **成功指标**：拿到书面法律意见，据此确认或修订一期功能边界
- **优先级说明**：在 [ADR-0006](adr/0006-G1最小验证路径.md) 砍掉三项授权阻塞后，
  **本项成为剩余的最高前置门槛**——它本来就该最先做。
