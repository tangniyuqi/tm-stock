# 业务概念与口径（tm-stock）

> 统一口径，避免同一个词在前后端/文档里各说各话。

## 核心概念

| 概念 | 定义 | 注意 |
|-----|------|------|
| **题材** | 市场围绕某一主题形成的关注集合（如"低空经济"） | 分**一/二/三级**；是本产品的核心载体 |
| **题材分类** | 题材库的目录层级（一级→二级→三级） | 与"产业链环节"**正交**，不要混 |
| **产业链环节** | 某题材内部的上下游分工（如光源→物镜→模块） | 是**题材详情页内部结构**，不是分类层级 |
| **事件** | 驱动题材的新闻/公告/政策 | 只做**客观转述 + 原文跳转** |
| **快讯** | 7×24 实时资讯流 | 来自第三方，**须先确认商用授权** |
| **题材涨跌幅** | 题材层面的派生统计指标 | **必须定义聚合口径**（如等权平均成分涨跌幅）并在 UI 可展开说明 |

## ⚠️ 两个正交结构（最容易搞混）

```
维度 A（题材库导航）:  一级分类 → 二级分类 → 三级题材
维度 B（题材详情内部）: 题材 → 产业链环节 → (个股：二期，一期不做)
```

**举例**：`半导体与电子`(L1) → `光学光电子`(L2) → `OCS 光交换`(L3)；
而 OCS 详情页内部的"光源 / 物镜 / 模块"是**产业链环节**，不是第四级分类。

## 一期数据边界

- 漏斗终点止于**产业链环节层**
- ❌ 一期**不存储、不展示**个股（成分股实体留二期持牌后）
- 题材/事件/快讯的每条数据都要有**来源可查**（source + url + 时间）
