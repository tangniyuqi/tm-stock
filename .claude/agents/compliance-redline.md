# 🔴 合规红线（最高优先级）

> **违反本文件 = 公司级法律风险（无牌证券投资咨询），比任何技术缺陷都严重。**
> 本文件为从严自评口径，**正式上线前须持牌证券律师书面复核**。
>
> **v2（2026-07-30 修订）**：v1 曾规定"一期不含个股"，**该口径过严且已被推翻**。
> 依据见 `docs/adr/0003-个股客观事实层可做.md`。修订要点：
> 判定的是**"有没有给出意见/建议/预测"，不是"有没有出现个股"**。

## 一句话

**不评价 · 不预测 · 不荐买卖 ·
个股只做「客观事实」呈现（分类归属 + 行情数据，依据可溯源）·
一期不做个股详情 · 用户自主判断。**

## 法律依据与判定逻辑

证监会《关于加强对利用"荐股软件"从事证券投资咨询业务监管的暂行规定》
（证监会公告〔2012〕40 号）第二条 +《证券法》第 160 条。
具备下列**任一**功能，即属须持牌的证券投资咨询业务：

1. 提供涉及具体证券投资品种的投资分析**意见**，或**预测**其价格走势
2. 提供具体证券投资品种**选择建议**
3. 提供具体证券投资品种**买卖时机建议**
4. 提供其他证券投资分析、预测或者**建议**

### 🔑 判定的关键落在「意见 / 建议 / 预测」上

四项要件的核心动词全是**规范性表述**（我方的主张），不是**事实陈述**。
因此真正的分界线是：

| | 性质 | 判定 |
|---|-----|------|
| "A 公司主营业务含光刻机零部件，属该题材成分股" | **事实**（可溯源至公告/年报） | 不构成荐股 |
| "A 公司今日涨 3.2%" | **事实**（行情数据） | 不构成荐股 |
| "A 公司是该题材**龙头**／**最受益**" | **我方评价** | ❌ 构成 |
| "该题材**即将爆发**" | **我方预测** | ❌ 构成 |
| "建议**关注/买入** A 公司" | **我方建议** | ❌ 构成 |

**行业实践佐证**：同花顺、东方财富、雪球、新浪财经等均展示"概念板块 → 成分股 → 涨跌幅"，
其中不乏无投顾牌照的财经资讯主体——因为这属于**行情与分类信息服务**，不属于投资咨询。

### ⚠️ 四个致命认知（务必记住）

- ⚠️ **不需要说"买"就已违规**：只要对个股做了**价值评价 / 投资价值排序**，就已落入定义。
- ⚠️ **免责声明不是护身符**：认定采「功能实质测试」，与页面写没写免责无关；
  结构违规时免责反成"明知故犯"证据。
- ⚠️ **牌照申不到**：证券投顾牌照 **2016 年起停发**，只能收购存量或与持牌机构实质合作。
- ⚠️ **"事实"必须真的是事实**：若"哪只股票属于哪个题材"来自我方主观判断而非公开依据，
  它就退化成了**品种选择**。→ 所以「**依据可溯源**」是本项目的合规命门（见下）。

## 🧭 合规命门：分类依据必须可溯源

平台要决定"把哪家公司挂到哪个题材的哪个环节"。这件事：

- 如果依据是**公开可查的事实**（公司公告 / 年报主营业务 / 招股书 / 官方产业目录），
  → 是**事实归集**，不构成品种选择。
- 如果依据是**我方判断**（"我们认为这家最相关"），
  → 就是**品种选择**，直接落入要件二。

**因此强制要求（同时也是产品护城河）：**

1. 每条「题材 ↔ 个股」映射，**必须存证据字段**：来源类型 + 原文摘录 + 原文链接 + 采集时点。
2. 详情页**可展示依据**（点击个股旁的"依据"可看到原文摘录与出处）。
3. 无依据的映射 **禁止入库**——宁可少收录，不可无据收录。
4. 排序只允许按**客观字段**（涨跌幅、成交额、市值、代码），**禁止**按"相关度/纯正度/受益度"排。

> 这条既是合规抓手，也正好是护城河：**可审计的题材库**是免费产品给不了的东西。

## ✅ 能做（客观信息侧）

| 可以 | 约束 |
|-----|------|
| 题材/行业/事件的**客观事实**呈现 | 是什么、因何政策或事件被关注 |
| 产业链**环节**划分与环节说明 | 客观分工描述 |
| **环节下挂具体公司**（成分股） | **必须依据可溯源**，见上节；不加任何评价标签 |
| **个股涨跌幅**（准实时 / 延时） | 须有**合法行情数据源授权**（见下节）；标注数据时点与延时口径 |
| 题材层 / 环节层的涨跌幅统计 | 标注口径（等权？市值加权？）与来源 |
| 按**客观字段**排序与筛选 | 涨跌幅、成交额、市值、代码；**不得**按主观评价排序 |
| 新闻/公告/政策的**客观转述 + 原文跳转** | 不加"利好/利空"定性 |
| AI 生成的**名词定义 + 公开事实复述** | 必须加护栏 + 标注"AI 生成" |
| 快讯聚合与全文搜索 | 第三方源**须先取得商用授权** |

## ❌ 绝不能做（红线）

| 禁止 | 为什么 |
|-----|-------|
| "龙头 / 受益标的 / 最受益 / 纯正度 / 真伪龙头"等**价值标注** | 对个股的投资价值评价 |
| 按"相关度 / 纯正度 / 受益程度 / 推荐指数"**排序或打分** | 构成投资价值排序 |
| **无客观依据**的高亮 / 置顶 / 首推某只个股 | 变相推荐（高亮必须是"用户选中态"或有明示的客观规则） |
| 涨跌**预测**、"将启动 / 即将爆发 / 黄金期 / 下一个轮动到"等择时表述 | 预测价格走势 |
| 目标价 / 买卖点 / 仓位建议 / 投资评级 | 买卖时机与选择建议 |
| **个股详情页**：基本面分析、财务评价、K 线与技术指标解读 | 对具体证券的投资分析意见（**一期整体不做**） |
| 个性化"为你推荐个股" / 自选股智能提示 | 选择建议 |
| AI 输出个股方向判断、收益承诺、买卖意见 | AI 荐股是监管重点打击区 |
| 基于行情异动的**触发式个股推送** | 带择时暗示的引导（一期不做） |
| 晒收益 / 战绩 / 胜率 / 历史推荐准确率 | 承诺收益类违规 |
| 把**无依据的主观映射**包装成"独家挖掘" | 品种选择 + 虚假宣传双重风险 |

## ⚠️ 灰区（需逐案判断，默认从严）

| 事项 | 说明 | 当前口径 |
|-----|------|---------|
| "领涨股"字段 | 客观事实（涨幅最高的成分股），但**读起来像背书** | 允许，但建议改中性名如"涨幅居前"；不得配"值得关注"类文案 |
| "热度"排序 | 若热度来自客观量（成交额/搜索量）则可；若来自我方打分则不可 | 必须公开口径 |
| 事件与个股**并置** | 客观归集（事件→题材→成分股）可；"因此利好这些股"不可 | 看**文案**，不看结构 |
| 转载快讯标题含违规词 | 原文转载不得篡改，但我方也不得自行创作此类标题 | 见下节 |

### 转载内容的处理（与代码层词表分工）

- 代码层的禁用词表**只管我方自己写的文案**（页面、按钮、AI 输出、营销）。
- 第三方快讯**原文转载**：不改标题、标注来源与原文链接、**不加我方定性**。
- 但**不得由我方创作**"这些板块将迎来黄金期"这类标题——**mock 数据同样受约束**
  （mock 文案最容易被直接沿用到正式版，实测已发生）。

## 📡 行情数据授权（独立于投顾牌照的硬约束）

> **这是一期最容易被忽略、且要真金白银的合规项。**

展示个股涨跌幅 = 使用沪深交易所行情数据。**商用必须获得授权**：

| 方式 | 说明 | 风险/成本 |
|-----|------|----------|
| 交易所或授权信息商签约 | 上证信息 / 深证信息 / 恒生 / 万得 / 同花顺开放平台等 | ✅ 合法，**有年费** |
| **延时行情（15 分钟）** | 授权门槛与费用显著低于实时 | ✅ **一期已定采用**（2026-07-30 董事长决策） |
| 抓取免费网页接口（新浪/腾讯/东财） | **无商用授权**，属数据抓取 | ❌ 侵权风险 + 随时被封 + 不可用于商业产品 |

**一期口径（已定）：延时 15 分钟行情。**

**要求**：
1. 页面**必须明示**"行情延时 15 分钟"，且展示**数据时点**（不是"刷新时间"）。
2. 数据源合同未落地前，**不得**上线真实行情；开发期用**明确标注的模拟数据**
   （"示例数据，非真实行情"，与「数据真实铁律」一并执行）。
3. 禁止使用未授权抓取源支撑正式产品。
4. 延时口径**不得**被产品文案暗示为实时（如"实时挖掘""秒级同步"）。

## 📝 文案禁用词（机器检查）

词表维护在 `scripts/compliance-forbidden-words.txt`，由
`scripts/check-compliance-words.sh` **自动检查**（已接入 L1 hook / L2 pre-commit / L3 门禁 / L4 CI）。

> 命名同样受限：产品/栏目/账号名避开"复盘、主线、风口、掘金、抓涨停"等投顾化词汇。

## 🏗️ 一期落地形态

- **平台**：仅 H5（uni-app x 编译 H5），暂不做原生 App 上架
- **卖点**：免费快讯引流 + **付费"题材查询"**（题材 → 产业链环节 → 成分股，全部为客观事实层）
- **个股边界**：只到"名称 + 涨跌幅 + 归属依据"；**不做个股详情页**（基本面/K线/技术指标）
- **支付**：App 内**不做自有在线支付**（走外部收款）→ 免经营性 ICP
- **付费墙**：可覆盖**数据与整理成果**（同 Wind/Choice 的数据订阅模式）；
  一期本就无"建议类"内容，故不存在"有偿提供投资咨询"

## 合规备案（一期轻量）

| 事项 | 一期是否必须 |
|-----|------------|
| 网站基础 ICP 备案 | ✅ 必须 |
| **行情数据商用授权** | ✅ **必须**（展示个股涨跌幅的前提） |
| 生成式 AI / 算法备案 + AI 内容标识 | ✅ 若使用 AI 解读则必须 |
| PIPL（手机号登录：告知同意、收集清单、注销） | ✅ 若收集手机号则必须 |
| 快讯第三方源商用授权 | ✅ 若聚合第三方快讯则必须 |
| 工信部 App 备案 | ❌ 免（仅 H5） |
| 经营性 ICP 许可 | ❌ 免（无自有在线支付） |
| 证券投资咨询牌照 | ❌ 免（严守客观事实层，不出具意见/建议/预测） |

## 遇到拿不准的怎么办

**默认从严**：不确定就按"存在风险"处理，先不做，问人。
**禁止**用"加个免责声明就行了"来说服自己——那不是合规抓手。
**自查三问**：这句话是**事实**还是**我方观点**？依据能**指到原文**吗？
去掉免责声明后它还站得住吗？
