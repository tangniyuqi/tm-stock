# 🔴 合规红线（最高优先级）

> **违反本文件 = 公司级法律风险（无牌证券投资咨询），比任何技术缺陷都严重。**
> 本文件为从严自评口径，**正式上线前须持牌证券律师书面复核**。

## 一句话

**不荐股 · 不预测 · AI 只分析到「题材 / 行业 / 事件」层 · 一期不含个股 · 用户自主判断。**

## 法律依据与判定逻辑

证监会《关于加强对利用"荐股软件"从事证券投资咨询业务监管的暂行规定》+《证券法》第 160 条：
只要具备下列**任一**功能，即属须持牌的证券投资咨询业务——

1. 对**具体证券**的投资价值进行分析、评价
2. **预测**具体证券的价格走势
3. 提供具体证券的**选择建议**
4. 提供**买卖时机**建议

**三个致命认知（务必记住）：**

- ⚠️ **不需要说"买"就已违规**：只要对个股做了价值分析/评级/排序，就已落入定义。
- ⚠️ **免责声明不是护身符**：认定采「功能实质测试」，与页面写没写免责无关；结构违规时免责反成"明知故犯"证据。
- ⚠️ **牌照申不到**：证券投顾牌照 **2016 年起停发**，只能收购存量或与持牌机构实质合作。

## ✅ 能做（客观信息侧）

| 可以 | 说明 |
|-----|------|
| 题材/行业/事件的**客观事实**呈现 | 是什么、因何政策或事件被关注、产业链有哪些环节 |
| 产业链**环节**的客观分工描述 | 上游/中游/下游各做什么（**不落到具体公司**） |
| **历史**涨跌幅的中性统计 | 标注数据来源与时点，不做趋势外推 |
| 新闻/公告/政策的**客观转述 + 原文跳转** | 不加"利好/利空"定性 |
| AI 生成的**名词定义 + 公开事实复述** | 必须加护栏 + 标注"AI 生成" |
| 快讯聚合与全文搜索 | 第三方源**须先取得商用授权** |

## ❌ 绝不能做（红线）

| 禁止 | 为什么 |
|-----|-------|
| **个股清单 / 成分股 / 个股涨跌幅** | 漏斗终点落到具体证券 = 帮助选择证券品种 |
| 涨幅榜 / 龙头榜 / 热度榜 / 任何绩效排序 | 构成选股池与价值排序 |
| "龙头 / 受益标的 / 纯正度 / 真伪龙头"标注 | 对个股的价值评价 |
| 涨跌**预测**、"轮动/下一个/将启动"择时表述 | 预测价格走势 |
| 目标价 / 买卖点 / 仓位建议 | 买卖时机建议 |
| 事件与个股**并置**（事件驱动选股） | 催化剂荐股形态 |
| AI 输出个股名/代码、方向判断、收益承诺 | 同上，且 AI 荐股是监管重点打击区 |
| 基于行情异动的**触发式推送** | 带择时暗示的引导 |
| 晒收益 / 战绩 / 胜率 | 承诺收益类违规 |
| 付费墙覆盖**个股相关内容** | 有偿提供投资咨询，坐实"获取经济利益"要件 |

## 📝 文案禁用词（机器检查）

以下词汇**不得出现在用户可见文案**中（页面、AI 输出、推送、营销）：

```
龙头  受益标的  最受益  纯正度  真伪龙头  金股  牛股  妖股
必涨  暴涨  翻倍  稳赚  抄底  抢筹  埋伏  潜伏  布局  加仓  建仓
目标价  买入  卖出  持有评级  推荐买入  强烈推荐
将启动  即将爆发  有望上涨  值得关注  机会来了  轮动到
```

**词表维护在** `scripts/compliance-forbidden-words.txt`，由
`scripts/check-compliance-words.sh` **自动检查**（已接入 L1 hook / L2 pre-commit / L3 门禁）。

> 命名同样受限：产品/栏目/账号名避开"宝典、复盘、主线、风口、掘金、抓涨停"等投顾化词汇。

## 🏗️ 一期落地形态（方案 C）

- **平台**：仅 H5（uni-app x 编译 H5），暂不做原生 App 上架
- **卖点**：免费快讯引流 + **付费"题材查询"**（只到题材/行业/产业链环节层）
- **支付**：App 内**不做自有在线支付**（走外部收款）→ 免经营性 ICP
- **前期不需要证券牌照**；个股能力整体后置到二期（须持牌或与持牌机构合作）

## 合规备案（一期轻量）

| 事项 | 一期是否必须 |
|-----|------------|
| 网站基础 ICP 备案 | ✅ 必须 |
| 生成式 AI / 算法备案 + AI 内容标识 | ✅ 若使用 AI 解读则必须 |
| PIPL（手机号登录：告知同意、收集清单、注销） | ✅ 若收集手机号则必须 |
| 工信部 App 备案 | ❌ 免（仅 H5） |
| 经营性 ICP 许可 | ❌ 免（无自有在线支付） |
| 证券投资咨询牌照 | ❌ 免（严守客观信息，不碰个股） |

## 遇到拿不准的怎么办

**默认从严**：不确定就按"存在风险"处理，先不做，问人。
**禁止**用"加个免责声明就行了"来说服自己——那不是合规抓手。
